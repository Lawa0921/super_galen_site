# M40 灰燼聖匣正式戰鬥

## 玩家體驗目標

M39 將世界觀拉回中世紀劍與魔法，但三幕仍主要是能力與資源選項。M40 要求每一幕先完成正式回合制遭遇，再處理符文、祝聖、談判或結局選擇。

## 三場遭遇

- 灰燼騎士守橋戰：架盾、激怒、聖／鈍弱點、火／斬抗性。
- 無舌唱詩班鎮魂戰：全隊震波、暈眩、亡魂護勢與多目標壓力。
- 龍燼化身決戰：範圍吐息、五點護勢、冰／聖弱點、火／斬抗性、半血激怒。

## 對抗審查

- 玩家頁無法未戰先結算幕次。
- 不能跳幕、重複領取勝利收據或利用舊分頁結算。
- 受傷旅伴不會被帶入，出征隊最多四人並沿用前後排。
- 敗北與撤退會留下養傷。
- 中途重整或關頁會留下嘗試收據；再次進入消耗乾糧，無糧則隊長養傷。
- M39 已完成幕次視為戰鬥已通過，舊存檔不倒退。
