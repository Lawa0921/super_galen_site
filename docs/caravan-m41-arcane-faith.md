# M41 — 秘法與神恩戰鬥資源

## 問題

法師與教士原本可以無限重複火球、隕石、治療與聖光爆。這讓魔法雖然有奇幻名稱，實際上卻只是另一組沒有代價的普通攻擊，劍士與遊俠在長戰鬥中的穩定性也沒有價值。

## 秘法

法師的秘法上限為 `clamp(4 + floor(INT / 5), 5, 9)`，每場戰鬥開始時全滿。

| 法術 | 秘法 |
|---|---:|
| 冰刺 | 1 |
| 火球 | 2 |
| 重力壓 | 2 |
| 寒冰束縛 | 2 |
| 隕石墜 | 4 |
| 秘法專注 | 回復 3，秘法灼傷 -1 |

未逐招登記的智力火焰／寒霜法術會取得保守預設成本，避免裝備或專精法術繞過資源。

## 過載

只有秘法法術可過載，且必須由玩家明確選擇。正常秘法不足時，點擊法術不會消耗回合。

反噬公式：

`2 + 秘法缺額 × 2 + 目前秘法灼傷 × 2`

過載後秘法歸零，秘法灼傷增加缺額，最高 5。灼傷達 3 以上時，施法者下一次行動暈眩。若反噬將使施法者倒下，過載選項直接停用。

## 神恩

教士神恩上限為 `clamp(2 + floor(CHA / 5), 4, 7)`，每場戰鬥以 1 點開始。

| 奇蹟 | 神恩 |
|---|---:|
| 聖擊 | 產生 1 |
| 戰地禱告 | 產生 1 |
| 治癒 | 1 |
| 聖光爆 | 2 |
| 戰吟 | 2 |
| 聖光治癒術 | 3 |

神恩不能過載。教士必須在攻擊、祈禱、治療與增益之間建立循環，而不是無限治療。

## 職業差異

- 劍士與遊俠的武技沒有資源成本，在魔力枯竭時仍可穩定輸出。
- 法師以高爆發、屬性弱點與過載風險換取戰場控制。
- 教士以聖擊或禱告取得神恩，再決定用於治療、範圍聖光或戰吟。
- 秘法與神恩是純戰鬥狀態，不寫入角色存檔，不會因重新載入舊存檔而缺欄位。

## 玩家對抗審查

- 物理角色不會被誤加資源或成本。
- 戰鬥初始化保留傳入角色物件身分，遠征 HP 與舊測試仍讀寫同一物件。
- 共用職業招式只建立安全副本，不修改 `JOBS` 全域資料。
- 正常資源不足不消耗回合，避免 UI 誤點懲罰。
- 過載必須明確選擇，且反噬逐次上升。
- 致命反噬不能執行。
- 純支援的專注與禱告能正確消耗一回合。
- 裝備與專精新增的火、冰、聖或治療招式不會默認免費。
- M39/M40 世界任務、敵人弱點、護勢與 Boss 激怒仍使用同一戰鬥核心。
