# Caravan M49 — Martial Engagement / 劍與魔法交戰距離

## 目標

M41–M48 已經讓「魔法」端形成秘法／神恩、過載、護法、儀式中斷、元素、護甲材質與穿甲等反制；但物理戰鬥的前後排主要仍只決定敵人先打誰。M49 不把遊戲改成戰棋，而是讓既有前後排真正影響武器使用，補齊《商隊與劍》中「劍」的一半。

## 規則

- **近戰在後排：命中 -2**。仍可出招，不做硬封鎖。
- **遠程在前排：命中 -2**。代表被近身壓迫時難以穩定瞄準。
- **真正的秘法／神術：不吃上述距離懲罰**。是否為魔法以 M41/M44 arcana 規則為準，不用斬／刺／打／火等表面元素猜測。
- **守勢攔截只允許前排**。後排角色仍可架盾保護自己，但不能隔空替前排同伴攔刀。
- 舊資料沒有 `formationRow` 時仍視為前排，維持舊存檔與既有測試相容。
- `Move.engagement` 提供資料層覆寫，讓未來的投槍、弩、長柄武器等不必改引擎。

## 為什麼不做更重的模擬

本作定位仍是文字跑團／商隊 RPG，不加入格子距離、命中部位、武器耐久、盾牌獨立裝備欄或每回合移動點。這些系統會提高維護與認知成本，卻不一定增加有意義的決策。M49 的目標是用一條玩家能記住的規則，讓站位和武器真正互相作用。

## 玩家視角多維度對抗審查

### 1. 新手可讀性

玩家只需要理解「劍靠前、弓靠後、法術不受這種距離限制」。錯誤站位不是不能玩，而是戰鬥紀錄明示 `命中 -2` 的原因，不會出現按鈕失效或隱性規則。

### 2. Build 多樣性

規則依 **招式／武器行為** 而非職業名稱判斷。跨職拿弓仍是遠程、拿劍仍是近戰；資料也能用 `engagement` 覆寫特殊武器。因此 M43 的跨職裝備不是假選擇。

### 3. 隊伍構築

- 劍士／近戰：前排取得完整命中，同時能用守勢攔截隊友。
- 游俠／弓弩：後排取得完整命中，前排仍能射擊但有壓力代價。
- 法師／教士：可在兩排維持施法精度，但仍會受到既有低防禦、前排受擊優先、護甲負重、秘法／神恩容量等成本制約。

因此沒有「全員同一排」可以同時最大化所有職業。

### 4. 戰鬥決策

M49 與既有系統疊加：

- 前排：承擔單體敵襲、能攔截、近戰完整輸出。
- 後排：降低被單體攻擊優先選中的風險、適合弓弩與脆弱施法者。
- 範圍攻擊仍能碰到後排，因此後排不是無條件安全區。
- M48 的鎖甲／輕甲／法袍／聖衣與 M44 護法照常在受擊後結算，不被 M49 取代。

### 5. 最優解／濫用檢查

拒絕以下容易破壞可玩性的方案：

- **禁止後排近戰或前排射擊**：會製造死按鈕與卡 Build。
- **給正確站位額外傷害倍率**：容易與弱點 ×1.5、裝備、專精形成爆炸乘區。
- **讓所有鈍擊自動破盾**：會把重力魔法等「魔法鈍擊」錯當物理武器，重犯 M48 修掉的分類問題。
- **後排守衛照樣攔截**：使前後排失去空間意義，已修正。

### 6. 長期擴充性

`engagement` 是資料層鉤子，不綁職業。後續可加入長槍／長柄武器（可覆寫為特殊距離）、弩、投槍、召喚／咒術等內容，而不用再重寫核心命中公式。
