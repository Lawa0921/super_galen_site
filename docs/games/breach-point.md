# Breach Point

`/games/cs`：Dungeon Arcade 的原創單人第一人稱戰術射擊，使用者選擇本次先完成單人打電腦。

## 遊玩

需要鍵盤、滑鼠與支援 WebGL 的桌面瀏覽器。從 `/games` 的 BREACH POINT 卡片進入，選攻方或守方；每隊三人，你有兩名電腦隊友，先贏四回合獲勝。

實際玩法驗收以桌面 Chromium 執行；Firefox、WebKit 與行動瀏覽器另驗證載入失敗提示和鍵鼠需求提示，未宣稱完整玩法跨瀏覽器通過。

| 操作 | 功能 |
|---|---|
| WASD / 滑鼠 | 移動 / 瞄準 |
| 左鍵 / 右鍵 | 射擊 / 穩定瞄準，狙擊槍開鏡 |
| R / Shift / Space | 換彈 / 慢走 / 跳躍 |
| 按住左 Ctrl | 蹲下：眼高 1.58→1.14 m、移速 34%、靜止散布 ×0.75、命中框下降 |
| 按住 E | 攻方安裝炸彈 3 秒；守方拆彈 5 秒 |
| B / Tab / Esc | 準備階段購買 / 計分板 / 暫停 |
| 4 / 滾輪 / 1 | 循環投擲物 / 槍與投擲物間切換 / 回到槍 |
| 投擲物：按住左鍵 / 右鍵 / 兩鍵 | 拉環後放開：遠投 / 近拋 / 中距 |

攻方炸彈手到 A 或 B 站定按住 E，移動或離開範圍會中斷。炸彈安裝後 35 秒爆炸；攻方即使全滅，只要炸彈已裝，回合仍會繼續。守方拆除炸彈或在未裝彈時守住時間即獲勝。陣亡後可觀戰，下一回合重生。

每回合有 12 秒購買時間，按「開始行動」可以提早開始。初始 $2400，勝回合 +$2400、敗回合 +$1600、擊殺 +$300，上限 $9000。陣亡失去武器與護甲。滑鼠靈敏度、音量、畫質保存在本機瀏覽器，私人模式無法儲存時仍可遊玩。

軍械庫顯示四把實際槍械、用途、單發基礎傷害、彈匣、換彈時間、目前裝備與資金不足原因。點選後立即扣款，換槍不退費；護甲獨立購買。

舊城中央市場分隔內側街道與外圍包抄路線，兩個爆破點後方各有低掩體。東側有 2.4 公尺高的石造通道，南北兩端各有 12 級樓梯；可以上下樓、跳躍或跳下邊緣。雷達以藍色區域標示高架路線。部分電腦隊員在 B 點進攻回合會走高架包抄。

活動邊界外有可見的石鋪街道、轉角建築與後排樓房，視覺地面延伸至 168 × 176 公尺。玩家仍受原本 48 × 56 公尺範圍限制，低石基和鐵欄提示邊界；眼高子彈可越過邊界命中外側建築，向高空射擊可落空。薄欄杆、門窗裝飾和屋頂小物不作精細彈道碰撞。

蹲下沿用 CS2 的按住式：約 0.15 秒平滑過渡，頭部／身體命中框與視線檢查同步下降 0.44 m，躲在 1.6 m 箱子後可完全隱身；暫停、陣亡、回合切換會放開。第三人稱以程序化骨架呈現（骨盆下沉、上身前傾但胸口與槍維持瞄準、雙腿 IK 讓腳維持原步態落點）。電腦在長距離狙擊／部分步槍對射時蹲下，並會在矮掩體後蹲著換彈。

射擊採即時命中，四把槍各有獨立爆光與回彈，並附短曳光、材質撞擊、彈殼和命中回饋。低幀率時槍身呈現最新一發的回彈，不累加已錯過的畫面；命中與彈藥仍按每一發計算。

## 投擲物（V37）

商店第三區販售 HE 手雷 $300、閃光彈 $200、煙霧彈 $300；HE 與煙霧各限 1、閃光限 2（總數上限 4，與 CS2 相同）。存活者保留到下一回合，陣亡即遺失（含已拉環未出手者）；本版沒有地面可撿的掉落物。

數值以本遊戲公尺尺度換算（CS 64u 眼高 → 1.58 m，1u ≈ 0.0247 m），程式在 `grenades.ts`：

- 投擲：出手速度 14 m/s（CS 約 16.7 m/s，地圖約為比賽圖一半所以下修）；右鍵 ×0.3、兩鍵 ×0.65；水平視角時上抬 10°，往上下看時遞減；繼承 1.25 倍跑速。取出 0.35 s 後才能拉環，拉環 0.25 s，出手後 0.5 s 換下一顆同類或回槍；取出投擲物會中斷換彈。
- 物理（`grenade-physics.ts`）：重力 7.9 m/s²（CS 0.4 × sv_gravity），彈性 0.45、撞擊切向保留 0.8、地面滾動摩擦 5 m/s²；與 `map-data.json` 障礙、樓梯/高台、外圍建築同一組碰撞體，以 240 Hz 子步避免穿牆。
- HE：引信 1.6 s；中心 98 傷害，高斯衰減（σ = 半徑/3）並在 8.6 m（CS 350u）歸零；護甲比 0.5、每點護甲擋 2 點；以腳、胸、頭三點對牆射線判定，不穿牆；不傷隊友（與子彈規則一致）但會傷自己；擊殺 +$300，擊殺訊息附「· HE 手雷」。
- 閃光：引信 1.6 s；視線被牆或煙擋住則無效；6 m 內全強度、34 m 歸零；面向夾角 cos ≥ 0.6 全強度、背對（≤ −0.3）剩 15%；最長白屏 4.9 s，最後至多 3 s 線性淡出，殘影為被閃當下的畫面；耳鳴為 Web Audio 兩個 3.1–3.3 kHz 正弦拍頻並壓低其他音量。敵我都會被閃，bot 白屏 > 35% 時看不到人、後退且不開火，恢復後仍需 0.6 s 反應；輕微白屏會放大瞄準誤差。
- 煙霧：落地靜止 0.25 s 才展開（6 s 保底）；半徑 3.5 m（CS 144u）、高約 3.3 m 的橢球，1 s 內長成，15 s 起淡出、18 s 消失，實際遮蔽約 17 s。遮蔽以光學深度 ∫密度·(1−ρ²) > 1 計算：核心不透明、邊緣淡。`map.visible()`（bot 視線）、隊友標記、閃光判定都會被煙擋住；子彈如同 CS 會穿過煙。
- Bots（`ai.ts`）：有餘錢（已買主武器與護甲後）才買；攻方輪流帶煙/閃，接近目標點 8–18 m 且視線清楚時，全隊一回合只丟一顆煙（封守方十字路口）和一顆閃；守方偶數位在 7–20 m 對看見的敵人丟 HE。友方閃光將爆時 bot 會轉頭避閃。

呈現：第一人稱沿用手槍資產的 48 骨 FPS 手臂（隱藏槍身），把 CC0 手雷模型掛在右手骨上，取出、拉環（拉環消失）、後拉、出手、收手都是程序化動作；手指仍是握槍姿勢，沒有逐指貼合手雷。第三人稱持手雷時槍隱藏、手雷掛在右手骨，拉環時右臂抬起、出手時前揮。煙霧為排序後的 instanced 柔邊 lump（每顆 64 片，最多 6 顆）並在 SSAO 之後合成，避免建築 AO 邊線印在煙上；站進煙內畫面為灰幕。HE 有火球、暗色塵雲與向外擴張的薄塵環，塵環中央及外緣保持透明；閃光爆點為短暫白光。手雷模型與 HUD 圖示來源見 `art-factory/cs/contracts/grenades-v37.asset-contract.json`（3DModelsCC0 Guns & Explosives，CC0）。

資產預算：`public/assets/games/cs/` 全部檔案上限由 32 MB 放寬為 34 MB（主代理決定；`fabric-detail-asset.test.ts` 同步）。理由：V37 新增 CC0 手雷 GLB 約 0.67 MB、三張 HUD 圖示約 8 KB，同期另有灰泥牆近景細節，原 32 MB 已剩不到 0.2 MB。

本階段使用 V38 `fx/utility-masks.webp`（75,328 bytes）呈現煙霧與爆炸，來源是 Kenney Particle Pack 1.1 的 CC0 素材。授權檔已核對，使用者已授權本階段 repository PR／merge 及其必要素材整合；最終來源選擇、人工美術與商用驗收仍待確認。詳 `art-factory/cs/contracts/utility-fx-v38.asset-contract.json`。

## 開發與驗證

- 頁面：`src/pages/games/cs.astro`；介面：`src/styles/_cs.scss`。
- 規則：`src/scripts/games/cs/engine.ts`，純 TypeScript，不依賴 DOM。
- 活動範圍、障礙與高差來源：`src/scripts/games/cs/map-data.json`；Blender 匯出依相同碰撞範圍核對。邊界外射線表面來自作者配方封存的 `city-surfaces.json`，不參與尋路。
- AI：`ai.ts`；尋路、碰撞、射線：`map.ts`。
- 瀏覽器：`client.ts`；Three.js：`renderer.ts`；音效為 Web Audio 即時合成。
- 美術來源、匯出腳本、機械 QA 與拒絕紀錄：`art-factory/cs/`；正式可載入檔：`public/assets/games/cs/`。
- 經核對的 v2 組裝截圖與審查：`art-factory/cs/runs/run-20261003-v2/qa/assembly-review.md`。模型來源是本次授權的 Blender 建模；沒有使用 Valve 資產。

Windows 使用 `npm.cmd ci --ignore-scripts`、`npm.cmd run dev`。Astro 7 在代理環境可能自動啟動背景程序；以 `npx.cmd astro dev status` 和實際程序/埠確認服務來源，避免停止別的 worktree。

```text
npx.cmd vitest run --maxWorkers=4
npx.cmd playwright test tests/e2e/games-cs.spec.ts tests/e2e/games-hall.spec.ts --project=chromium --workers=1
npx.cmd playwright test --workers=4
npm.cmd run build
```

多人房間、排行榜與公開部署不屬於本次單人交付。遊戲使用原創素材，與 Valve 無關。
