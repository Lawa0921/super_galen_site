## 已實際驗證

- 10 項 Python 測試通過：兩段 IK、固定腳點、機構時序、連續肘解、不可達腕角與共線回歸；保留先失敗再通過的紀錄。
- `preservation.json`：人體與手套的位置、拓樸、權重、UV 完全相同；四個非 Attack 動作每 1/8 幀比較原 44 骨的世界矩陣，最大分量誤差 1.61e-6。換 parent 時清除舊局部鍵值，再重新烘焙，避免舊的中間鍵值殘留。
- `glb-validation.json`：兩 LOD 均 0 errors／warnings／infos；49 骨與新增裝備存在、五個動作齊全、Attack 實際為 3 秒。
- `browser/report.json`：實際 GLB hash 一致；兩陣營、兩 LOD、五個動作共 20 組播放／暫停、79 張姿勢截圖、手機畫面、0 page errors。
- Vitest：134 files／1,383 tests 通過，105.57 秒。沒有 runtime 邏輯修改，本輪沒有重跑 production build、全站 E2E、自然戰役、效能或新版戰場／肖像組裝；以前的結果不作為這版美術通過的證明。

## 明確未通過的項目

`fullbody-deformation.json` 對實際 Blender 曲線做每 1/16 幀、共 1,153 個姿勢的檢查：腕彎最大 76.547°、腳底固定、地面不穿透、槓桿接觸誤差小於 0.0007 mm、箭手相對矩陣分量誤差小於 6.5e-7，這些項目通過。

以下仍失敗，不能因瀏覽器和格式檢查通過而忽略：

1. 47.5625 幀手臂骨端距離誤差 3.890 mm；48.9375 幀相鄰 1/16 幀角步達 28.224°。原本 176.56° 的翻轉已縮小，但快速轉動與插值仍不合格。
2. 41.625 幀袖口三角面面積比最低 0.03329，最大 4.75927；上臂、袖口在完整人物畫面仍有不自然扭折，不能只調整測試門檻。
3. `held-bolt-collision.json`：50–62 幀手箭都有 162 組三角相交；56.5／57／62 幀箭與弩分別有 26／14／82 組相交，62 幀手與弩另有 85 組。這些是相交調查訊號，尚無穿透深度與語意面分類；骨骼指尖對到點不代表真實指腹已成立。

獨立唯讀複核確認：取箭已移到弩外側，動作因果比第一版清楚；目前判定為 `qa_failed` 正確。完整表面碰撞、LOD 變形、GLB 密集頂點 parity、原創角色整體美術與效能都未通過。

## 接續工作

先以真實拇指／食指表面重做細箭夾持，檢查握點是否落在箭羽，讓其他手指避開箭桿；用實際網格碰撞建立可行接觸姿勢。之後重新安排放箭終點與轉向路徑，再處理手臂肘部平面、旋轉和袖口的變形分配。不要再以指骨端點接近或單一腕角數值代替整體外觀驗收。

修復優先檢查 41.625、47.5625、48.9375、56.5、57、62 幀，再擴大完整五動作與 LOD 檢核。唯有角色整體合格後，才以 TDD 接上 runtime：現在弩兵仍在攻擊開始便發射，間隔 1.7 秒；候選放弦在 0.5 秒、完整動作 3 秒，兩者尚未同步。

衛兵整體甲胄及其他兵種仍待原創重製與商用品質驗收。已完成的河谷地形整合不重做，也不縮減使用者對人物、所有兵種及動態肖像的要求。
