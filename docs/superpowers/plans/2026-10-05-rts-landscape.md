# 兩張 RTS 地圖景觀增豐

使用者要求：目前地圖太單調；沿用「直接開始」授權。沿用唯一美術來源 `2026-10-04-browser-rts-design.md`。

範圍：以生成地表混合取代單一重複草地；雙河谷地加入濕潤草甸、碎石河灘、疏林，灰脊隘口加入灰岩碎石、乾草、成群岩脊。重用正式 oak / rock 模型，新增群落避開基地、路線、資源與營地；實體足跡對應導航。平面戰鬥、橋口、迷霧、選取與動態大頭貼維持現有契約。

1. 生成四格地表來源，切片、接縫與大小 QA，保存 contract / prompt / hash / 候選。
2. TDD：景觀分布可重現，兩圖差異，保護區與可達性，遮罩有限且正規化，instancing 迷霧／釋放。
3. 實作混合地表、岩岸／林地配置與批次化靜態景觀；整合既有資源樹木。
4. 實際開兩圖檢查基地、橋／隘口、遠近鏡頭、建造／採集與迷霧。獨立唯讀審查。
5. 全套 Vitest、RTS strict TypeScript、相關瀏覽器測試、production build、正式負載效能與下載預算。留可點 preview、截圖與限制。

驗收：開局就看得到大尺度地表層次，兩圖環境可分辨；路線與資源仍清楚；新增景觀不可穿越、不可洩漏迷霧；1080p 80 單位／20 建築／動態大頭貼中位數 >=55 FPS、p95 <33ms；首圖壓縮資產 <=35MB。
