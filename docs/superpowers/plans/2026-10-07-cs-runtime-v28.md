# V28：市場動線、射擊回饋與軍械庫

使用者要求：改善仍不及格的美術、增加地圖複雜度、強化開槍效果、重做選擇武器畫面。沿用 CS2／CS:GO 寫實方向與單人對電腦玩法，背景測試。此輪是 runtime 可見改善，不再延伸 V27 未通過的手部候選。

## 範圍與設計

- 地圖維持現有尺寸及 A／B 點，增加中央單層市場、兩側接續掩體及站點後方掩體，形成內路／外包／前後橫向連接。依使用者「兩者都要」加入東側 2.4m 高台、南北各 12 級樓梯；玩家腳底支撐、半徑碰撞、AI 路線、視線、音效遮蔽、彈道與炸彈位置均使用相同高度資料。
- 美術沿用已核准 CC0 材質、建築構件及原作 Blender 建模。新市場有石基、木門、百葉窗、棚架和屋頂細節，避免與三層住宅重複。保留 V24 地面修正與 V26 合批。
- 軍械庫採四張實際模型商品圖＋明確價格、武器用途和數值，突出目前裝備、可用資金與無法購買的原因；護甲獨立列，保留既有字型與鍵鼠流程。模型 render 衍生圖走素材契約、來源、透明 QA、登錄流程。
- 射擊使用依武器區分的瞬間槍口爆光、較可見的短曳光／撞擊、槍身回彈與有衝擊的聲音包絡；不改即時命中規則，不新增持續光源，不增加無界粒子或 GPU 配置。

## 實作與驗收順序

1. 已完成原版原生流程截圖（tmp/cs-v28/before），頁面無錯誤。
2. 先寫軍械庫狀態、FX 時間／界限、地圖連通與射線失敗測試。
3. 建立素材契約並製作四張武器圖與新環境候選。候選 QA 後才放 runtime，保留來源和舊版。
4. 實作 UI／回饋／map-data 同步；全套 Vitest、受影響 Python QA、相關 Chromium E2E、production build。
5. 原生背景操作買槍、開火、換彈、暫停及新路線；桌面／窄畫面截圖與獨立唯讀檢核。新增場景保持有限 draw calls／材質／檔案大小。若進行時間量測，序列執行、不與 Blender 或其他測試競爭，記錄硬體條件。
