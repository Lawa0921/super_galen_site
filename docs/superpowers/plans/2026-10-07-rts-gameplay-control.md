# RTS 玩法優先：基本調度與命令可靠性

使用者於本輪確認人物仍未達可用品質，要求先專注玩法。暫停人物、美術與動畫修整；沿用原 RTS 規格和現有資產。本輪由主代理唯一寫入，探索與審查代理唯讀，保留工作樹全部既有修改。

## 範圍與驗收

1. 主城對可見資源設集結點，新工人完成後自動採集；普通地點集結仍可用。資源枯竭沿用現有重新尋找機制；失去視野時先前往已知資源位置，不能提前讀取枯竭結果。敵方資源集結意圖不經 TeamView 暴露。
2. 小地圖可設建築集結點；A + 左鍵或右鍵能向小地圖下攻擊移動，成功後退出瞄準模式；失敗保留模式。普通左鍵仍移動鏡頭，不攔截建造／技能目標模式。
3. 牧師遵守明確攻擊／普通移動命令；閒置、守備和攻擊移動仍自動治療。移動舊問題是施法當下停一個 tick，不能描述成永久卡死。
4. 攻城車自動索敵至少涵蓋自身 12 公尺射程，仍受視野限制；普通近戰的既有警戒半徑與守備不追擊語意保留。

不在本輪新增種族、兵種、改模型、調整成本／HP／傷害平衡或大改 AI。窄路友軍阻擋的持續等待問題另外保留，先不把它混入上述命令修正。

回歸測試新增發現：木工滿載返城時，浮點誤差會讓兩個等距入口排序互換，導致反覆重算路徑並原地打轉。納入本輪修正；等距候選保留固定枚舉順序，驗證實際入庫，並保留方向改變時選擇較近入口的行為。
