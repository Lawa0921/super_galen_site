# 原創河谷與橋面修整

沿用唯一王國美術指南與原創生成地表、石橋來源。主代理唯一寫入，探索／審查代理唯讀。

第一個上凸拼接岸段因外觀像管子淘汰；第二個維持原 4m 阻擋帶的淺河槽沒有足夠視覺改善。最後採連續蜿蜒河道，水位 -.8m、河床 -1.25m，岸線回到兩個既有橋位。原 blocked hash 不再作美術限制，改驗證可見河道與導航一致。

1. 保存原實際 Battlefield 兩圖遠近與採集證據。
2. 保存淘汰原始 Blender 與截圖，不將其加入 runtime。
3. 候選改河道阻擋、18 個原創石頭位置與兩個橋頭擴張礦位置；資源 ID、總量、主基地、兩條路線及營地保留。
4. 原石橋基底高度 2.695m，八塊實際鋪石頂高 2.8756–3.0095m；原角色固定 y=0 會走橋下。使用原可編輯物件調平鋪石、整橋落位，將石橋作為可見走面，河床從橋下穿過。橋材質、UV、拓撲維持原始來源。
5. 橋頭裁切地面道路；霧層跟隨岸、水與橋面。TDD 驗地形、來源 UV、拓撲接面、最大單位可達與自然 AI 對戰。
6. 在獨立組裝頁切原圖／候選、南北橋、全圖／已探索／開局視野，實際 command + simulation 操作工人過橋；跑 full Vitest、嚴格型別、GLB validator、獨立審查。

交付是可操作河谷候選；尚未替換正式地圖／registry。角色、所有兵種動畫與 3D 大頭貼仍屬完整目標，不能以此地圖里程碑宣告遊戲商用品質完成。
