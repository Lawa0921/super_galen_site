# CS 城市外延與建模細節 V32

使用者要求提高建模精細度，並確認問題是「越過建築後只剩天空／空白」。視覺場景必須超出活動範圍，保留單人打電腦、既有動線與效能優先要求。沿用唯一美術指南 `2026-10-03-browser-cs-design.md` 和原作者 Blender／既有 CC0 PBR 資產。

活動範圍仍是 X ±24m、Z ±28m，玩家半徑 .36m；14 個場內障礙與 25 個高差實體不改。第一圈完整建築、門窗、招牌、圓頂和石塔整體外退 8m，形成可見外街。低石基、鍛鐵欄杆與角接頭提示活動邊界；四角加入組裝式返回立面，地面延伸至 X ±84m、Z ±88m。外圍十棟後排建物有三種高度／材質，露出前排屋頂。近景補倒角石柱蓋、窗台托座、金屬合頁與插銷。

零件在合批前由來源建立。35 個 Blender collection assets、79 個 linked instances 保留 local parts 與 scene placements；runtime 使用材質合批。既有 source ownership 逐面一對一遷移，避免按世界座標隨意切割 runtime 網格。量化位置外移後改存 Float32，所有舊面依原索引順序驗證：world POSITION 誤差上限 10 微米，其他屬性誤差上限 2e-6；另單獨驗證材質／圖片 payload 與 collider nodes。原始 V31 快照留在本次 raw/。本版保留既有授權石牆零件，細化重點是街廓、欄杆與窗戶五金。

射線與移動限制分離。作者產出的建築殼、低石基 proxy 封存成 `city-surfaces.json`，AI 視線與子彈共用；移除原 bounds 的無限高射線牆。薄鐵欄、窗飾和屋頂小物是裝飾，不改導航。打高空仍能落空。

最終預算：150,000 環境三角面、32 材質 primitives、18 MB 環境 GLB、28 MB 全 runtime 資產、零新增貼圖。相較早期 140,000 面草案，增加屋頂可見度後上調幾何上限，並以頂點去重、合批與實機高低畫質量測控制成本。

驗收：來源一對一映射與原有 83,734 面逐面保護；108 條整圈／角落眼高幾何射線、9 條外地面射線；重開 Blender 驗證引用／材質／實例矩陣；玩家視角、抬頭和近景截圖；完整 unit、Python、CS Chromium E2E、build；原生遊玩高低畫質各 180 秒背景量測。紀錄失敗候選與修正證據，不以編譯或總面數相同代替通過。未對外部署。

效能檢查另發現解析度切換會重複配置畫布及後處理緩衝區。本版以單次 drawing-buffer 設定、固定 composer DPR=1／實體像素尺寸、直接半解析度 SSAO 配置及各自尺寸快取修正；低畫質的後處理維持 1×1。同尺寸重複 resize 不配置資源。保留首次低畫質 P95 超標、兩組 CPU 診斷及修正前重測；這項配置修正不等同於已查明所有持續慢速區段的原因。
