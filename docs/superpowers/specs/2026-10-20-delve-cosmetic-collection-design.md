# DELVE 外觀收集制 — 設計

日期：2026-10-20 · 狀態：設計定稿待使用者審閱 · 前置：PR #296（種族衣櫥 + 角色/世界分存 + 選角選世界，已上線）

## 1. 為什麼

使用者原話：「一些外觀裝備應該要是在遊戲過程當中收集，不是一開始就有」「建角色只能決定外觀或是特徵、種族等」。

現況（master cbe31d0e）：
- 衣櫥（`engine/appearance.ts` + `render/wardrobe.ts`）的 14 套服裝、9 個頭飾（+「無」）、眼鏡，建角時和遊戲中**全部免費可選**，沒有任何解鎖。
- 另有一套已經要收集的「時裝道具」（`engine/vanity.ts`、`engine/items.ts:383-411`，21 件，頭 / 身體 / 腿 / 背 4 格），來源是工作台合成、寶箱（`engine/loot.ts chestFashion`）、商人。穿上會蓋過衣櫥選的外觀（`engine/doll.ts buildDollLook`：時裝欄 > 護甲 > 基底服裝）。
- 種族可在遊戲中衣櫥隨時換，被動能力即時跟著換（`game.ts raceMods()`）。

收集的樂趣被免費衣櫥吃掉了；而且同一件「水手服」同時是免費選項又是要做的道具，規則打架。

## 2. 目標

1. **建角只決定身體**：種族、體型、膚色、髮型、髮色、瞳色、眼型、腮紅、呆毛。衣服與飾品不在建角選單裡。
2. **穿戴的東西全部靠收集**：14 套服裝、9 個頭飾、眼鏡都變成**物品**，和現有 21 件時裝道具併成同一套系統。
3. **取得方式：製作、打怪、開寶箱**（使用者指定）。現有商人販售的時裝保留，不新增商人來源。
4. **物品形式（使用者選的 1）**：佔背包格、可丟、可放箱子、之後連線可以交給朋友。不是永久解鎖圖鑑。
5. **種族建角後固定**，只能用特殊道具「轉生之藥」更換。
6. **身體特徵（種族以外）在「梳妝台」更改**：可製作的家具，放著就能用，免費。
7. **舊角色外觀不變**：既有角色現在穿的服裝 / 頭飾 / 眼鏡，在轉換時變成他擁有、且已穿上的物品。

## 3. 非目標

- 造型師 NPC（梳妝台就夠；之後要加，用同一個選單）。
- 染料道具（每件衣服的主色 / 副色在梳妝台免費重新配，見 C4）。
- 時裝收集圖鑑 / 收集進度 UI。
- 新增新的服裝款式或新美術（只把現有款式轉成物品；轉生之藥、梳妝台、基本布衣需要新圖示 / 新畫法）。
- 連線本身（M-B 以後）。這次只保證物品是一般物品，日後能交易。

## 4. 反目標（做到了也算失敗）

- 舊玩家打開遊戲發現角色衣服被扒光、或頭飾不見。
- 和平模式（不生怪）的世界裡有任何一件外觀**永遠拿不到**。
- 新角色前 10 分鐘內拿不到任何一件新衣服（收集要有立即的第一個獎勵）。
- 一個世界就能把全部外觀刷齊、或要刷上百隻同一種怪才掉（數值由 builder 拿捏，但兩端都算失敗）。
- 建角畫面變得空洞：身體選項仍要完整可玩，預覽照舊。

## 5. 使用者已決定的「怎麼做」

| 項目 | 決定 |
|---|---|
| 建角可選 | 種族、體型、膚色、髮型、髮色、瞳色、眼型、腮紅、呆毛（＋ 主色 / 副色，見下） |
| 服裝 / 頭飾 / 眼鏡 | 變成物品；來源 = 製作、打怪、寶箱 |
| 物品 vs 解鎖 | 物品（佔格、可丟、可交易） |
| 種族更換 | 只能靠特殊道具 |
| 身體特徵更換 | 設施或 NPC → 本設計選「梳妝台」家具（Claude 的提議，使用者同意開工） |

## 6. Claude 代為決定（使用者可推翻）

- C1 **新角色穿「基本布衣」**：新增一個基底服裝選項（依 `appearance.ts` 規定 append 在選項陣列最後，存檔存 index），樸素、不算物品、永遠穿著。時裝欄空著時就顯示它。建角預覽也穿它。
- C2 **頭飾與眼鏡放進新的第 5 格時裝欄「飾品」**（`acc`）。帽子仍在「頭」格；帽子與飾品可同時穿，遮擋規則沿用現有 `HAT_HIDES_TOP` 一類的繪製邏輯。眼鏡與髮飾共用飾品格，一次只能戴一件（現在可以蝴蝶結＋眼鏡同時戴 → 轉換時見 C6）。
- C3 **14 套服裝的物品形式**：每套服裝要能用物品完整重現今天的樣子。已經存在的對應時裝（例如水手服上衣 + 百褶裙）直接算數；沒有對應物品的服裝新增物品。一套是 1 件（身體）還是 2 件（身體 + 腿），由 builder 依現有繪製方式決定，但同一套的件數在全部服裝間要一致可預期。
- C4 **每件衣服各自記自己的顏色（使用者決定）**：
  - 服裝 / 時裝物品帶「主色、副色」兩個顏色值（存在物品實例上，跟著物品走：放箱子、丟地上、日後交給朋友都保留）。
  - 新取得的物品是該款式的原色（現在的預設顏色）。
  - 梳妝台可免費替「身上正穿著的」每件衣服重新配色；基本布衣的顏色存在角色外觀上，同樣在梳妝台調、建角時也能調。不做染料道具。
  - 顏色不同的同款物品視為不同物品（不可疊成一堆，或疊堆時保留各自顏色——builder 依現有物品堆疊結構擇一，不能讓顏色在疊堆時消失）。
  - 渲染：時裝物品改用物品上的顏色繪製（取代現在固定用款式預設色），快取鍵要含顏色。
  - 舊角色轉換（C6）時，把他目前外觀上的主色 / 副色寫進轉換出來的那件服裝物品，外觀因此完全不變。現有已收集的 21 件時裝道具沒有顏色資料 → 視為原色，看起來和現在一樣。
- C5 **梳妝台**：
  - 前期就能在工作台做（用前期材料，例如木頭 + 其他前期素材；builder 依現有配方表挑），放置後靠近互動開啟「梳妝」選單。
  - 選單 = 現在的衣櫥介面，只保留身體特徵列 + 「身上每件衣服的主色 / 副色」（C4），**沒有種族、服裝、頭飾、眼鏡**。免費。
  - 遊戲內選單的「角色外觀」按鈕（`#delve-look-menu`）移除。
  - 連線時：誰都能用房主世界裡的梳妝台，改的是自己的角色。
- C6 **既有角色的轉換**（讀到舊角色檔時一次性執行，之後不再執行）：
  - 他目前的服裝（非基本布衣）→ 對應物品；頭飾（非「無」）→ 對應物品；有戴眼鏡 → 眼鏡物品。
  - 放置順序：對應時裝欄是空的、**而且該部位沒有正在顯示的護甲**（有護甲但設了「隱藏」算沒有）就直接穿上；否則放進背包；背包也滿就放進他目前所在世界、他腳邊的掉落物（與現有 `giveOrDrop` 一致）。理由：繪製順序是時裝欄 > 護甲 > 基底服裝（`engine/doll.ts`），硬穿上會把原本露出的護甲蓋掉，外觀就變了；「外觀不變」優先於「直接穿上」。
  - 頭飾與眼鏡同時有時：頭飾穿進飾品格，眼鏡進背包。
  - 轉換出來的服裝物品帶上角色原本的主色 / 副色（C4）。
  - 轉換後基底服裝設為基本布衣，所以外觀由時裝欄重現；畫面上看起來要和轉換前一樣（例外：頭飾 + 眼鏡同戴的人，眼鏡在背包；有露出的護甲時，衣服在背包，但畫面本來就顯示護甲）。
  - 轉換要可測、只做一次（角色檔加版本或旗標），不得重複發放物品。
- C7 **轉生之藥**：消耗品。使用時開種族選單（顯示 5 族與被動說明），選定即換、藥水消失；取消則不消耗。取得：每個王**對這個角色而言**的首殺必掉 1 瓶（用角色檔既有的已擊敗王紀錄 `levels.bosses` 判斷，紀錄跟著角色走，開新世界重打不會再「首殺」），之後再打該王有小機率掉（builder 定機率，量級約 10–25%）。不可製作、不在商店。和平模式世界沒有王 → 另放進少量高級寶箱（遺物 / 寶藏箱）低機率出現，確保和平模式也拿得到。
- C8 **來源分配原則**（實際每件放哪裡由 builder 依現有怪物、配方、寶箱表決定，寫成一張表放進計畫）：
  - 每件外觀至少一個來源；**只靠打怪才拿得到的外觀，必須另有寶箱或製作來源**（和平模式）。
  - 約三分之一可製作（前中期材料），其中至少 1 件只用開局附近就有的材料，讓新角色 10 分鐘內做得出來。
  - 主題怪掉主題款（例如忍者類怪 → 忍者裝束）；高稀有款（小皇冠、偶像舞台裝、哥德洋裝這類）放王 / 寶藏箱 / 地城箱。
  - 現有時裝的來源不移除（現在做得出來的還是做得出來）。
- C9 **建角流程**：新角色面板的衣櫥只顯示身體特徵列 + 種族 + 主色 / 副色；預覽穿基本布衣。`delve.appearance`（預設外觀）照舊記身體部分。
- C10 **種族在梳妝台與遊戲內都不能改**，只有轉生之藥。

## 7. 限制

- 存檔：外觀存 index，新選項只能 append；角色檔要能讀舊版（PR #296 剛上線的 `cformat: 1`）並一次性轉換（C6）。舊格式整合存檔（format 9）照現有轉換路徑先變角色檔，再套 C6。
- 文字繁體中文寫死（delve 不走 i18n）；禁 `!important`、禁行內樣式；不加 npm 套件。
- 美術全部程式繪製（Canvas2D）；新物品圖示比照現有物品圖示的畫法。
- 測試：`npx vitest run`、`npx playwright test tests/e2e/delve.spec.ts --project=chromium`；`tests/e2e/delve.spec.ts` 是 CRLF。

## 8. 留給 builder

- 每件外觀的具體來源、掉率、配方材料（遵守 C8 原則，產出一張表）。
- 物品 id 命名、圖示畫法、時裝欄第 5 格在背包 UI 的位置。
- 一套服裝 1 件或 2 件（C3）。
- 梳妝台的家具尺寸與外觀、互動距離。
- 轉生之藥在和平模式寶箱的機率。
