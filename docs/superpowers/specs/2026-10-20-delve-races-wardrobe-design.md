# DELVE 種族與造型擴充 — 設計

日期：2026-10-20　分支：`feat/delve-races`（自 master `6322fb3a`）

## 意圖

使用者對 /games/delve 的回饋：「角色本身」不夠好看、「衣服選擇不夠」、「可以選擇種族會更有趣」。
使用者選擇跳過細節訪談、直接開工，以下除標註「使用者說」者外，皆為**實作方（Claude）的判斷**，使用者可推翻。

## 目標

1. **種族**（使用者說要有）：人類 / 精靈 / 矮人 / 貓族 / 龍裔，五選一，在角色外觀畫面選。
   - 外觀差異：精靈＝長尖耳；貓族＝貓耳＋尾巴（隨髮色）；龍裔＝雙角＋鱗尾；矮人＝矮兩格＋男性有鬍子（隨髮色）；人類＝現況。
   - 小被動（判斷：讓選擇有意義但不破壞平衡）：人類 XP +10%；精靈 光照 +1；矮人 挖掘速度 ×1.15；貓族 安全落下 +6 格、跳躍 ×1.08；龍裔 燃燒傷害 ×0.5、岩漿傷害 ×0.75。
2. **更多衣服**（使用者說不夠）：服裝 6 → 14：忍者裝束、魔導長袍、騎士罩袍、旗袍、海盜外套、偶像舞台裝、神官袍、哥德洋裝。
   髮型 +4（低馬尾、狼尾、大波浪捲、側分長瀏海）；頭飾 +4（小皇冠、耳機、狐狸面具、髮簪）。
3. **角色本身畫質**（使用者說不夠好）：
   - 修 bug：`pixel.ts snap()` 只查 `PALETTE`，把頭髮外框 / 膚色等 avatar 專用色錯映射成灰藍 → 外觀預覽、HUD、手臂出現灰色殘影。
   - 衣服三階明暗、手臂與軀幹之間有可讀的分隔。
   - 外觀預覽放大（桌面 6×），可切換面向。

## 非目標

- 新衣服**不**做成遊戲內可撿的時裝道具（只在角色外觀選）——之後另案。
- NPC 不新增種族（矮人 NPC 維持現況）；但 NPC 的髮型 / 服裝隨機池改用完整清單。
- 不改存檔格式版本（`race` 缺值 = 人類）。
- 連線不在本案（見 `2026-10-20-delve-coop-design.md`）。

## 反目標（做了也算失敗）

- 舊存檔 / 舊 localStorage 外觀讀進來壞掉或變臉。
- 帽子 / 頭盔下穿出耳朵、角，或遮住眼睛。
- 手持物蓋到矮人的臉。
- 任何新美術用了調色盤外的顏色或半透明像素（既有 `clean()` 測試）。
- 預覽畫布非整數倍縮放（既有 `expectCrisp` e2e）。

## 約束

- 所有美術以程式即時生成（標題畫面的承諾）；不引入圖檔。
- 新顏色必須進 `PALETTE_HEX` 或 `AVATAR_*_HEX`。
- 測試：`npx vitest run src/scripts/games/delve` 全綠；`npx playwright test tests/e2e/delve.spec.ts --project=chromium` 全綠。
- 樣式：SCSS / astro `<style>`，禁 `!important`、禁行內樣式。
