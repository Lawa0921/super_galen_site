## 0. 一頁摘要

- **主題句**：靠忘記活不下去，一個人扛也走不回來；記憶要分著扛，人才回得了家。
- **為什麼現在演起來怪**：人物只有過去，沒有現在。八位夥伴有四位的轉折是同一招：「以為自己失敗了，其實沒有」，而且都發生在回憶裡。凜被揭穿是刺客，隊上卻沒有一個人有反應。洛恩的美德是「什麼也不問」，結果他連被背叛都不痛。終幕沒有任何人付出代價。
- **怎麼改**：
  1. 給每個人一個現在的慾望，以及一個會傷到別人的缺點。四段赦免回憶的轉折改成她在現在做一個選擇（§7.6）。
  2. 每位夥伴至少和兩位夥伴有真正的摩擦：日常裡包在笑話底下，在重戲裡真正撞上。
  3. 凜的揭露要有後果：回城那天的晚飯，她對全隊坦白（`rin-confess`）。
  4. 鐘守是凜的師父，也是上一輪在市集裡殺死洛恩的人（裁定 a）。
  5. 洛恩出發前想一個人下去，被攔下（`hero-alone`）。
  6. 終幕讓洛恩把找回的十片記憶交給燈。手冊的筆記留著，瑪莎在星燈祭念日記，大家替他記著這一輪（裁定 d）。
- **改動量**：
  - 新增三場主線重大場景：`rin-confess`、`hero-alone`，以及從 6e 提前的 `epilogue`（星燈祭）核心；
  - 十四個新的閒聊編號（十段新內容、四段舊內容換編號）、一段回城對話；
  - 改寫凜的揭露、鐘守來到鎮上、終幕、第三幕兩句，以及凜第四片、瑟蕾第五片、波比第五片與四段赦免回憶（希爾薇、絲嘉蕾、莎菲拉、諾艾兒）；
  - 葛倫的交還照裁定 b 改寫；
  - 合計約一百五十句。
- **Tasks 1–7 要改的部分**：約兩成。
  - `rin-reveal` 改三句、換一處順序；
  - `bellkeeper-arrives` 整場加長；
  - `mem:rin:4` 改一句旁白；
  - `act3` 兩句。
  - 其餘保留，而且其中好幾處（繃帶、門邊、眨眼、湯、發抖的手）正是這次的伏筆。
- **結構與引擎**：見 §9.3，逐條列出。

## 1. 診斷：為什麼演出很奇怪

### 1.1 人物只有過去，沒有現在
- 八位夥伴的弧線，全部發生在回憶裡。現在的她們只負責「聽到回憶的反應」，不需要選擇、不需要放棄任何東西。
- 其中四位的轉折是同一招「我以為我失敗了 → 其實不是我的錯」：
  - 希爾薇：`mem:sylvie:4`（story:715–722）「林子，我還是沒守住」，翻成 `mem:sylvie:5`（story:724–731）「人，我都帶出去了」。
  - 絲嘉蕾：`mem:scarlet:3`（story:983–990）「我逃了」，翻成 `mem:scarlet:5`（story:1001–1008）「我不是逃走的」。
  - 莎菲拉：`mem:safira:2`（story:634–641）「是我先看見那座城的」，翻成 `mem:safira:4`、`5`（story:652–668）「做決定的，不是我」。
  - 諾艾兒：`mem:noel:2`（story:768–775）「小氣鬼」，翻成 `mem:noel:4`（story:786–793）「是怕我把自己燒光」。
- 同一種赦免看到第三次，玩家就不信了；赦免由回憶送上門，不是她自己掙來的。
- 唯一在現在做選擇的人是凜（`rin-reveal`），所以全劇只有一條線有戲。
- 修正見 §7.6：赦免照舊來自回憶，但轉折的那一拍放在現在，由她自己做一件事。

### 1.2 關係是宣告的，不是掙來的
- `chat:selene:2`（story:550）「您每一次，都把大家帶回來了」：玩家沒看過任何一次「他把大家帶回來」的場面。
- `chat:scarlet:2` 集滿版（story:1025）「替你擋下……是我想這麼做」：沒有任何一場戲讓她產生「想」的理由。
- 終幕的八句（story:1038–1057）全部建立在「相遇那一刻」上（帳本 I-110），一場四句的相遇要撐起高潮。
- 瑟蕾第五片（story:532）「我不怕了」：她沒有在現在面對過任何一次恐懼。

### 1.3 夥伴之間沒有摩擦
- 二十二段閒聊（story:1201–1424）全部收在一個笑點或一個溫暖上，沒有一段有立場衝突。
- 最接近衝突的 `noel-rin:1`（story:1213–1221）也只是單方面的玩笑。
- 夥伴只對洛恩有感情，彼此之間只有綽號。玩家看到的像八個人輪流跟洛恩約會，不像一支出生入死的隊伍。

### 1.4 揭露沒有後果
- `rin-reveal`（story:418–434）是全遊戲最暗的一場。之後：
  - 隊上沒有一個人知道；
  - `bellkeeper-arrives`（story:438–448）在廣場上演，夥伴不在場；
  - 夥伴的對話與閒聊一字不變。
- 被派來殺隊長的人睡在隊長房裡，立誓當盾的絲嘉蕾卻沒有反應：這是「人物很假」最直接的來源。
- story:429「他沒有問為什麼，像是早就知道」：洛恩連被背叛都沒有情緒，她放下的刀對他來說像不存在。

### 1.5 洛恩沒有缺點，只有美德
- 他的招牌動作是「什麼也不問」：
  - `mem:rin:5` story:179；
  - `act2` story:231；
  - `townLines.act3` story:1704；
  - story:429。
- 這本來可以是缺點（逃避、怕失去），現在卻被寫成聖人式的溫柔。
- 序章的慾望（想知道自己是誰，story:111）之後再也沒有和任何東西衝突。
- 終幕「送到這裡就好」（story:1037）之後，隊友各說一句，他就接受了，沒有任何掙扎。

### 1.6 結局沒有代價
- 波比的閥讓「交出去的也不會失去」（帳本 I-111，story:1055–1057）。
- 燈亮、霧散、光回去，沒有人失去任何東西。
- 圓滿結局要有價格，觀眾才相信它。

### 1.7 揭露沒有鋪陳
- 鐘守在凜選擇之前沒有臉、沒有私人關係，「我只是想看清楚你」（story:445）沒有理由。
- 波比的閥只在 `mem:bobby:5`（story:868）出現一次。
- 燈鑰的工匠就是波比的祖先（帳本 I-46），玩家從來沒機會知道。
- 安娜的三個同伴（story:1109–1112）講完就斷線。

### 1.8 情緒跳接
- 在回憶的四句裡，從罪惡感到「我自己選的」只用一句：`mem:scarlet:5` story:1006、`mem:sylvie:5` story:729、`mem:selene:5` story:532。
- `rin-reveal`：刀尖抵喉，接到「明天也一起回來吧」，中間沒有一句洛恩自己的話。

### 1.9 每個人都對每個人好
- 鎮民一律溫暖。第三幕證實他死過很多次、靜鐘會的教義是「他走到哪，霧就跟到哪」之後，鎮上沒有一個人怕他。只有序章一句井邊婦人的玩笑（story:1682）。
- 社會壓力是零，所以安娜「一直空著那一欄」（story:247）也沒有對抗什麼。

### 1.10 做得好、要保留的
- **伏筆紀律**（繃帶、湯、眨眼、指痕、門邊）：`first-return`（story:122–136）是全劇最好的一場戲，這次三個回收從它出發。
- **莉茲與歐里克**的雙向相認（帳本 I-75、I-87）。
- **凜的七片**的節奏。
- **鎮民的固定梗與日常的笑點密度**：不要為了深度把日常寫沉。

## 2. 主題

> **靠忘記活不下去，一個人扛也走不回來；記憶要分著扛，人才回得了家。**

世界觀已經有這三種做法：
- 艾斯特拉想忘，把悲傷倒進燈裡，長出迷宮；
- 洛恩不肯忘，可是一個人記住，就成了永遠的燈芯；
- 終幕要的是第三種：分著扛。洛恩交出自己找回的記憶，這一輪由手冊、日記和身邊的人替他記著。

| 人物 | 原本怎麼處理記憶 | 弧線的答案 |
|---|---|---|
| 洛恩 | 一個人扛 | 讓大家分著扛；交出找回的十片，這一輪由大家記著 |
| 凜 | 被別人抹掉：童年被做成刀 | 把自己的事說出口，讓隊上的人知道她是誰 |
| 鐘守（凜的師父） | 抹掉別人：劃名單、殺走出來的人 | 記住：留在鎮上，「剩下的日子拿來記住」（只屬於他自己，不和凜和解） |
| 瑟蕾 | 不說，責任推給月亮 | 說出口：「是我說的，不是月亮」 |
| 千鶴 | 替死人扛 | 為活人扛：鈴掛在哪裡，哪裡就是神社 |
| 莎菲拉 | 跑贏它 | 停下來，把他們一個一個想一遍 |
| 希爾薇 | 不讓別人扛她 | 收下別人做的東西；自己種下種子 |
| 諾艾兒 | 燒掉記憶換力量 | 撕下那一頁，親手還給老師 |
| 波比 | 替祖先扛 | 把愧疚做成一道閥，讓燈也能分著扛 |
| 莉茲 | 用錢扛 | 回去本身就是還債 |
| 絲嘉蕾 | 用身體扛：替人死 | 站到旁邊，不是前面；活下去 |
| 安娜 | 替每一個人登記，因為鬆開過手 | 撕掉門口的紙；找回同伴的登記表 |
| 瑪莎 | 日記寫給一個沒回來的人 | 日記寫給所有回來的人；星燈祭念給洛恩聽 |
| 葛倫 | 守門，卻忘了替殺手指過路 | 天沒亮就站在門前；想起來之後不再逃那件事 |

## 3. 人物表

格式：慾望／需要／傷口／缺點與謊言／秘密／道德底線與掙扎／各階段的弧線／可愛的地方。
夥伴另加「好感與戀愛線」，給 6e 的寫作者；心契場景一律**不告白**（好感 spec §8.1），讀起來是深厚的信任；九位的份量相同，凜不寫成預設的女主角。

### 3.1 洛恩（主角）
- **慾望**：知道自己是誰（story:111）。第四幕以後：不讓任何人替他付代價。
- **需要**：讓別人分著扛；承認自己也會怕、也會想要。
- **傷口**：
  - 數不清的死亡與遺忘；
  - 第一輪「城裡只剩你還記得」（story:370）；
  - 每一輪都在鎮上交朋友，然後失去他們。
- **缺點與謊言**：
  - 「下面的事，本來就是一個人的。」
  - 「不問，就不會失去。」他的不問是怕，問了凜就會走。
  - 照顧所有人，唯獨不照顧自己（繃帶）。
- **秘密**：他是守燈人（第九片才知道）。
- **道德底線與掙扎**：絕不讓任何人替他燒。這條線本身就是他的問題，終幕他要跨過它。
- **弧線**：
  - **序章、第一幕**：空白的人；吐槽役；想知道自己是誰。
  - **第二幕**：察覺凜不對勁，選擇不問。
  - **第三幕**：
    - 知道自己被殺過很多次；
    - 公會門口有人貼紙；
    - 第一次回頭看身後的霧（story:248，保留）。
  - **第四幕**：
    - 凜的揭露：他只多說一句真話「一直沒問，是怕一問，妳就走了」；
    - 坦白的晚飯：「這一趟下去，她還是走在我後面」；
    - 第九片之後，出發的清晨想一個人下去，被攔下。
  - **終幕**：他把找回的十片記憶交給燈，當作閥的「第一段不回來的光」。他最初的慾望（知道自己是誰），被他自己交了出去；手冊裡的筆記還在，這一輪由大家記著。
- **可愛的地方**：
  - 平平地吐槽；
  - 什麼都一學就會，夥伴覺得不公平；
  - 說夢話（凜數過，三次）；
  - 緊張時摸劍柄上溫溫的紋路；
  - 把最後一碗湯推給別人，被瑪莎推回來。

### 3.2 凜
- **慾望**：揭露前，是找回自己、說不出理由地跟著他；揭露後，是留下來。
- **需要**：
  - 承認行為是自己做的（不是「身體自己動的」）；
  - 讓隊上的人知道她是誰。
- **傷口**：
  - 鐘樓下的童年；
  - 丟中才有湯；
  - 被撐開的眼皮；
  - 師父是她唯一的家人，而師父把她做成刀。
- **缺點與謊言**：
  - 「我是工具，手會自己動。」（`first-return` story:127）
  - 揭露前的冷面與「沒事」是同一件事：不讓任何人碰到她。
- **秘密**：
  - 她的任務（第六、七片）；
  - 第三幕在舊登記簿上看見名單最後那個名字（`act3` 新句），從那天起，她開始藏一件說不清的事。
- **道德底線與掙扎**：
  - 刀尖抵在他喉嚨上的那一夜；
  - 第二個掙扎：要不要讓全隊知道。她說了（`rin-confess`）。
- **與師父**：她叫他「師父」，之後一句話也不再對他說。終幕把敲平的鐘交出去，沒有原諒，也沒有恨的台詞（裁定 a）。
- **弧線**：
  - **序章、第一幕**：唯一的線索；同一盞燈；坐在門邊（`first-return`）。
  - **第二幕**：喝湯的樣子不對勁；按著銅鐘；走在他後面。
  - **第三幕**：
    - 避開視線；
    - 在登記簿上認出最後一筆的名字；
    - 希爾薇說她「走路像在追獵物」（`rin-sylvie:1`）；
    - 和瑟蕾互相戳破「說一半」與「沒事」（`rin-selene:1`）。
  - **第四幕**：
    - 旅館那一夜（`rin-reveal`）；
    - 回城那天的晚飯對全隊坦白（`rin-confess`）；
    - 師父來到鎮上（`bellkeeper-arrives`）；
    - 絲嘉蕾守門的第七個晚上（`rin-scarlet:2`）；
    - 出發的清晨坐在門邊攔住他（`hero-alone`）。
  - **終幕**：她的手疊上他的手；鐘交出去；最後一句由她說（保留）。
- **可愛的地方**：
  - 多餘的精準數字；
  - 一個詞的判決；
  - 做了好事就挑剔來掩飾；
  - 選擇之後多眨幾下眼；
  - 對貓沒有抵抗力。
- **好感與戀愛線**：
  - `bond:rin:1`、`2`（揭露前）：她問他問題，卻不回答他的；
  - `bond:rin:3`（誓約後）：第一次開口要一樣東西：一碗不用一口喝完的湯；
  - 心契（不告白）：「不是因為你抓住我的手。是因為那之後，每次回城，你都等我。」

## 5. 主要衝突脊椎

### 5.1 序章與第一幕（本道一到三層）
- 外在：兩個失憶的人下去，打倒燈喰之獸，霧散三天又回來。

- 改動：無。

### 5.2 第二幕（四到九層）
- 外在：迷宮是燈壞了長出來的；夥伴陸續相遇。
- 內在：凜的回憶開始不對勁（第四片的名單，改成抄來的，§7.2）；洛恩選擇不問。
- 人際：

  - `liz-scarlet:2`（絲嘉蕾兩片以上）；
  - `safira-sylvie:2`（莎菲拉兩片以上）。
- 兩難：莉茲賣掉有名字的碎片，或交還。她交了，賠掉兩倍的錢，也傷了絲嘉蕾。

### 5.3 第三幕（十到十五層）
- 外在：
  - 舊登記簿；

  - 安娜：照規矩安撫鎮民，或照良心。她選良心，失去三個會員。
  - 葛倫（交還時）：想起自己替穿長袍的人指過路。

### 5.4 第四幕（十六到二十九層）
- 外在：艾斯特拉、守燈人的傳說；凜第七片；師父來到鎮上。
- 內在：
  - 凜要不要動手、要不要說；
  - 洛恩第九片之後，要不要一個人下去。
- 兩難：
  1. **凜**：說出來，會失去隊上的信任，也讓師父知道；不說，就永遠站在別人背後。她說了。代價：絲嘉蕾七個晚上的守門，莉茲當面算帳。
  2. **瑟蕾**：承認自己早就看見，就是承認沉默可能害死他。她承認了（第五片的現在，或 `rin-selene:2`）。
  3. **絲嘉蕾**：趕走凜，或尊重洛恩。她兩個都要：留下凜，自己守門。代價：七個晚上。
  4. **洛恩**：一個人下去，或帶大家下去。他被攔下來。代價：接受別人為他付出，這對他比死還難。

### 5.5 終幕（第三十層）與星燈祭
- **兩難**：
  - 燈要記憶才能點亮；
  - 洛恩說交出去的就回不來；
  - 大家照樣交出關於他的記憶，相信自己會失去它（這是她們的勇氣）；
  - 波比的閥能把光還回去，但第一次點火要「一段不回來的光」（第五片的伏筆）。
- **代價（裁定 d）**：
  - 洛恩把他找回的十片記憶（以前每一輪的日子、艾斯特拉、階梯口那句「要回來」）交給燈，當作那一段不回來的光；
  - 「要回來」的約定，他已經做到了，所以可以放手。
  - 手冊留著：回憶可以重看，那是他的筆記，不再是他的記憶。這就是主題。
  - 戰鬥能力不變（手還記得，見 §9.2 待定）。
- **凜**：把敲平的鐘交給師父，沒有台詞。
- **鐘守**：「……是我殺的。」
- **收尾**：凜的最後一句（保留）。
- **星燈祭（主線，裁定 d）**：終幕後第一次回城，瑪莎把日記念給洛恩聽，安娜翻開他的那一張；這一輪由她們記著。

### 樣稿一：`banter:rin-scarlet:2`（輕的閒聊，笑點底下有真的摩擦）
- 閘門：`oath: true`、`seen: ['rin-confess']`。
- 時間點：絲嘉蕾在坦白那頓晚飯說「我有我的做法」，從那晚起守門；這是守夜表上的第七個晚上。
- 規則檢查：
  - 四句；先笑點（凜的精準數字），刺放中間，收在一個笑點加一個小溫暖（文風聖經 §2.5）；
  - 凜選擇之後不用「呢」；絲嘉蕾叫「〇〇小姐」、不用語尾助詞；
  - 沒有「……」與驚嘆號；
  - 「吵」回呼 `rin-scarlet:1`。

```
凜（normal）：「第七個晚上。妳的鎧甲今晚響了四十一次，比昨晚少了三次。」
絲嘉蕾（serious）：「我在練習不動。今晚是守夜表上的最後一班，總要守得像樣。」

```

為什麼這樣寫：
- 笑點是凜數了四十一次、絲嘉蕾在「練習不動」；摩擦是凜直接說破「妳守的是我」。
- 絲嘉蕾不辯解，騎士不說謊：她的誠實既是冒犯，也是尊重。
- 凜不走、不生氣，她接受被懷疑。關係往前一步，沒有和好；和好留給 `:3`。
