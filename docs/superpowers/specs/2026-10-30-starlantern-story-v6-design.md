## 1. 世界：兩層

### 1.1 第一層：大家相信的（鎮上的常識）

**露米亞是淘金鎮**
- 迷宮是某一天出現的，誰也說不清是哪一年、為什麼。
- 下面有寶物、素材、裝備，以及會發光的結晶（碎片）。
- 冒險者來這裡，有的想發財、有的想出名、有的想找「聽說在最下面的東西」。
- 公會發下潛許可、湊隊伍、收購戰利品、登記失憶的人。「探索」就是這些。

**星燈**
- 西邊高地上的光柱，迷路的人朝它走（帳本 I-97）。最近好像比較暗。
- 沒有人把它和迷宮連在一起。「光柱只是燈罩，燈芯在最底下」只是公會老酒鬼的醉話（I-31 保留為醉話）。

**暮霧**：已知的危險，只有民間說法。
- 大家知道的：
  - 下得太深的人回不來，或回來時一片空白；
  - 霧濃的日子，鎮上的人會忘東西。
- 霧是什麼沒有人知道。民間說法互相矛盾，當作日常的梗反覆出現（I-230）：

| 誰說 | 說法 |
|---|---|
| 酒館 | 迷宮在睡覺，霧是它打的呵欠 |
| 瑪莎 | 下面的人在煮湯的蒸氣，霧濃就多煮一鍋 |
| 歐里克 | 霧大，燈好賣 |
| 老冒險者 | 死在下面的人嘆的氣 |
| 公會 | 「原因不明，請勿久留。」 |
| 諾艾兒 | 魔力的廢氣，碎片是廢氣結成的渣 |
| 千鶴 | 山神不高興 |
| 瑟蕾 | 有人哭不完的眼淚（說完就收回；最接近真相） |

**碎片**
- 大家以為是魔法結晶：交易所收得好，有人拿來吸收變強。
- 「吸太多會變空殼」是鎮上流傳的說法（I-232：空殼的定義照舊）。
- **沒有人知道碎片裡裝著記憶。**
- **回憶光點（R21）**：洛恩與凜自己的回憶片（`mem:hero:*`、`mem:rin:*`）在迷宮裡看起來就是一塊發光的結晶，別人眼裡和無主碎片一樣。只有洛恩或凜伸手去拿時，它才化進他們身上；隊友看見的是「撿起來，就化掉了」。夥伴的五段是她家鄉的遺物，不是光點（§6.4）。

**洛恩**
- 「歸來者」，有史以來唯一從最底下走上來的人。這是一個傳說。
- 大家想跟他組隊，以為他知道寶藏在哪。他什麼都不知道。
- **為什麼這一次成了傳說（R27）**：
  - 公會的登記簿裡，以前每隔幾十年就有一筆「洛」。每一筆都被登記成一般的、下得太深而回來時一片空白的冒險者，彼此隔幾十年，沒有人把它們連起來；安娜來得太晚，一個也沒見過。
  - 這一次，葛倫親眼看見他從深處的門走上來，手裡拖著昏迷的凜（I-02），劍上的紋路是亮的。所以鎮上叫他「歸來者」。
  - 葛倫十七歲那年也看過上一輪，但那一段被霧拿走了（I-90）。
  - 第三幕的登記簿揭露的，就是「這些一片空白的人，其實是同一個人」。

**凜**：被他拖出來的女孩（I-02，葛倫親眼看見）。鎮上不叫她歸來者。

### 1.2 第二層：真相

1. **艾斯特拉造了星燈，保存逝者的記憶。**
   - 戰後全城把悲傷倒進燈裡，光變質，燈根長成迷宮。地面的光柱是燈罩（照舊）。
2. **燈其實在關住霧。**
   - 燈吞下的記憶太多，關不住的就成了暮霧；燈越乾，霧越多。
   - **燈要是熄了，裡面的一切會像洪水一樣漫上地面。**
3. **霧漫到哪裡，迷宮就吞到哪裡**，長成新的地區：沙漠、森林、要塞、神社的山。被吞的人與事凝成碎片。
4. **守燈人（照舊）**
   - 第一輪，艾斯特拉最後一個不肯忘記的人自願下去，用自己的記憶點燈。
   - 燈芯燒完，燈把他吐回地面，什麼都不記得，只握著燈鑰（劍）。他會被引回深處再點一次。那個人就是洛恩。
5. **只有洛恩聽得見碎片**：碎片是燈的光的一部分，燈鑰與燈芯認得它們（§9）。
6. **鎮民各丟了一段記憶**：被鎮上的霧拿走，凝成碎片掉在迷宮裡。他們不知道碎片裡有自己的東西（§7）。
7. **只有洛恩與凜走出來**：燈只往上送守燈人；凜在出口前被霧吞掉時，被他抓著手腕，一起被拉上來（I-02、I-17）。
8. **靜鐘會**：見 §3。
9. **終幕**
   - 波比祖先造的燈少一道閥，只會吞、不會還。修好閥，燈能把光還給主人，不必再有人燒盡自己。
   - 靜鐘會的願望（結束輪迴）用相反的方法達成。鐘守的最後一聲鐘，意思是「結束了」。

## 2. 資訊邊界

### 2.1 失憶（只有洛恩與凜）

- **霧拿走**：自己這一生的經歷（人、地方、事件、為什麼）。
- **霧留下**：語言、常識、身體記得的技能與習慣。
- **他們能知道的只有四種**：
  1. 醒來時身上的東西；
  2. 身體的習慣；
  3. 沒有前後文的碎片：一句話、一個聲音、一種感覺；
  4. 醒來以後的事，包括別人告訴他們的。
- **失憶要在台詞裡看得見**，每場至少一次，當喜劇也當心酸：
  - 拿「醒來這幾天」比較一切；
  - 會做卻不知道為什麼；
  - 被問到過去就答不出來；
  - 聽別人轉述自己（「葛倫說，是你把我拖出來的」）。
- **失憶不是笨**：醒來以後學到的事要記得。

### 2.2 鎮民：一個洞

- 每位鎮民只丟了一段特定的記憶，其他人生都在。
- 他們繞著那個洞說話、避開它，被碰到時會停一拍或轉話題。
- 他們**不知道**那段記憶在碎片裡，直到洛恩還給他們。

### 2.3 夥伴：知道，但還不說

- 她們記得自己是誰、為什麼來。她們有一件**還不肯說的事**，台詞要讓人感覺到「她故意跳過了什麼」，而不是「她想不起來」。
- **例外一：諾艾兒**（R31）。書裡那一頁的星火，**每念一次就燒掉一點**她自己的記憶；燒掉最大的一塊，是**老師的臉和名字**。這是她自己的魔法造成的，和霧無關；她知道自己燒過，但不知道燒掉了哪些、多少。
- **例外二：千鶴**。她沒有失憶，只是被冰封了幾十年，時間錯亂。她昏迷時被一支冒險者隊伍抬出來，所以以為露米亞是她那座山腳下的村子（R41）。

### 2.4 檢查清單（寫手與審查共用）

1. 誰在說？現在是第幾幕？她說到第幾段了？
2. 這句話裡有沒有她「還不知道」的事（洛恩、凜、鎮民），或她「還不肯說」的事（夥伴）？
3. 她引用的事實從哪來？身上的東西、身體的習慣、碎片、聽說（要說得出誰說的），或已經演過的場景。
4. 目標說法有沒有偷跑理由？（✗「存一千枚還債」；✓「存到一千枚，別問為什麼」）
5. 鎮民有沒有直接說破自己的洞？
6. 有沒有人比他該知道的更懂迷宮、燈、霧？（§1.3 的階梯）
7. 這一場的失憶（洛恩、凜）或秘密（夥伴）有沒有被看見？

## 4. 洛恩

### 4.1 驅動力與目標

- **醒來時有的**：刻紋的劍、一個字「洛」、一句話「**我答應過要回去**」。這句話是醒來時嘴裡在念的；葛倫說他倒下前念了兩遍。
- **目標**：查出答應了誰。他相信總有一片碎片會告訴他，所以每一片都先聽，不是他的就送去公會找主人。
- **他也有很小、很具體的想要**：吃飽、不欠公會錢（序章到第一幕）、問一句就得到一句直接的回答。
- **有主見**：會反對、會吵、會拍板。夥伴吵起來時，由他定案。
- **缺陷**（照故事深度 §3.1）：一個人扛；不問就不會失去。
  - 新的矛盾：他在找自己答應了誰，卻很少答應眼前的人。

### 4.2 心聲（新的台詞類型）

- 洛恩心裡的話，用括號（）包，畫面上用不同的樣式，讓玩家永遠知道他在想什麼。
- 每場一到三句，負責兩件事：**好笑**，和**他真正擔心的事**。不寫旁白，不描述畫面。
- 他不知道的事，心聲也不知道（§2.1）。
- 資料形狀、介面、測試，見 §10.2 與計畫 PR 2 的 Task 2.0（R36）。

### 4.3 十片回憶（R19）

- 無主碎片永遠不是他的。
- 他自己的十片（現行 `mem:hero:1–10`，落點不變）是前幾輪留下的殘響。前九片都沒說他答應了誰；**第十片**才說出：是艾斯特拉送行的人（I-46）。
- 「我答應過要回去」是每一輪燒完以後唯一留下的一句（I-231）。

## 5. 凜

- **失憶**：同 §2.1。

## 9. 碎片聽力（R5、R8、R21、R23、R24）

### 9.1 時序：先聽見，再認出

1. **第一次聽見（第一幕）**：洛恩撿到或吸收碎片時，偶爾跳一句心聲（§9.2）。第一句是「（……它在說話？）」，之後越來越具體（「在哭」「在數羊」）。他不知道說話的是誰；凜說她什麼都沒聽見。
2. **第一次認出主人（瑪莎，R21）**：
   - 瑪莎的碎片照現行設定掉（本道五層起，`TOWN_FRAGMENTS` 不改）。
   - 撿到之後的第一次回城，旅館廚房演 `town:marta` 的認出版：洛恩聽出那是瑪莎的聲音，把碎片還給她，她想起來了。
   - 這一場就是瑪莎的交還，不經過公會的選單。
3. **其他鎮民的碎片（R23）**：
   - 照常掉，`lootFragments` 與 `expect.ts` 都不動，抽取次數不變。
   - 在 `town:marta` 演過之前，介面上顯示成「認不出的聲音」，不能交還，只能帶著。
   - 演過之後，名字才出現，公會開始替碎片找主人。
4. **沒拿到瑪莎碎片的玩家（退路）**：
   - 瑪莎的碎片只在必經的本道掉，到終幕之前幾乎一定會拿到。
   - 若始終沒拿到：
     - 其他鎮民的碎片一直是「認不出的聲音」。它們是選擇性的內容，不擋主線。
     - 第二幕的牆照「還沒認出」的讀法播。
     - 星燈祭照現行 `notReturned` 的讀法播（`S:1431-1434`）。
   - 遊戲照樣能通關。

### 9.2 只動顯示的呈現

1. **撿到碎片**：撿取提示偶爾接一句洛恩的心聲（文字池約二十句，第一句固定是「（……它在說話？）」）。只顯示，不影響數值。挑句子用確定性的索引，不抽任何亂數。
2. **吸收**：`absorb` 的三十三句陌生人台詞保留，改成「洛恩聽見：「……」」的呈現；別的夥伴吸收時，也是洛恩在旁邊聽見。
3. **賣碎片**：第一幕之後，交易所賣出時偶爾跳一句心聲（「（又賣掉一個人的一天。）」）。不改價格。
4. **回憶光點**：洛恩與凜的回憶片，在迷宮裡是一塊會化進他們身上的結晶（§1.1）；提示照舊是「〇〇想起了什麼。」。

## 10. 文風與測試（摘要）

### 10.1 文風（詳見聖經 §1.6 到 §1.8）

- **活俠傳式對話**：人物直接說自己要什麼；每句接上一句；笑點出自本性與情境、當場說破；玩笑底下有真心；每場要有衝突、或帶出想法、或帶出特色。
- **撤掉三條把文字推向格言的規則**：
  - 「結尾停在畫面或短話」（舊聖經 §1.2）；
  - 「群戲最後一句是旁白的畫面」（舊 §1.5）；
  - 「說出口的通常比心裡想的少一半」（舊 §1.1）。
- 用語避開武俠腔：千鶴的「〇〇姑娘」改「〇〇小姐」；「一刻鐘」改「一會兒」或「煮一壺湯的時間」（R38）；歐里克叫年輕女孩「小姐」。

### 10.2 心聲的資料形狀

- `ScriptLine` 加 `inner?: true`，只准 `who: 'hero'`。文字用（）包。
- 介面：沒有名牌（或名牌寫「心聲」），不同的顏色加斜體，頭像照舊。
- 和羈絆選項的（）動作，靠旗標區分；選項不准帶 `inner`。

### 10.3 測試規則的改變（細節在計畫）

| 項目 | 改成 |
|---|---|
| 句數上限 `lineCap` | 回城對話 8、閒聊 10、相遇 6／12、新的 `join:*` 24、交還 16、群戲 26、歸鄉 8、羈絆第一到三段 10、第四段 14、終幕 20（`MAJOR_CAPS`）；**回憶與坦白（R30）**：夥伴的坦白 `mem:<c>:n` 14；洛恩與凜的回憶 8，`mem:hero:9`、`mem:hero:10`、`mem:rin:7` 14 |

| 新的劇透測試（R18、R22、R30） | (a) `town:marta` 看過之前：洛恩以外的人、以及 §9.3 列出的介面字串，不准在同一句裡把「碎片」和「記憶、主人、誰的、還給、交還」連在一起（`S:2367` 的「主人是誰」就是這一條要抓的）。(b) 分說話者：鎮民（安娜、歐里克、瑪莎、葛倫、多蘭、商人）**在終幕之前**不准在同一句把「燈」和「迷宮」連在一起；夥伴在 `act2` 看過之前不准；洛恩、鐘守不受限。(c) 安娜的禁詞（§7.2）。(d) 帶燈的教義片語（「被燈燒」「燈就會熄」「燈自然熄」「讓燈熄」）只准出現在凜第六片以後、帶 `if.oath: true` 的句子、`AFTER_CHOICE` 場景、鐘守的句子；不帶燈的「讓他休息」最早從凜第四片起 |

| `frozenScenes.test.ts` | 解凍（R14）：在 PR 8 重錄 `finale` 與 `epilogue` 的快照，commit 訊息引用 R14 |

### 10.4 冷讀（W7）的新題目

1. 這是人在對話嗎？標出像旁白、像格言、像在寫作文的句子。
2. 每一場：誰想要什麼？誰擋著？你更清楚誰在乎什麼了嗎？
3. 接話測試：標出沒有接上一句的台詞。
4. 說得出每個人的目標與進度嗎？
5. 這一場洛恩想要什麼、在想什麼、做了什麼決定？
6. 誰知道得太多了？挑出「這個人現在不可能知道」或「她現在還不會說」的句子。
7. 盲測十句各是誰說的（至少八句對）。
8. 劇透檢查（照 W8 的對照組作法）。
