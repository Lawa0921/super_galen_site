## 0. 問題在哪裡（controller 的診斷，加上本次的分類統計）

- 343 句台詞裡有 232 句用了「……」。
- 幾乎每個人都用同一個句型：短短一句，接「……」，再補一句感傷的話。

## 1. 不變的事

這一輪只改「怎麼說」，下面這些全部不動：

- 每個人的核心個性、背景、記憶線的內容。
- 揭露表裡每個秘密揭露的時間點：凜的任務（凜第 6、7 片）、洛恩是守燈人（主角第 9 片）、劍是燈鑰（主角第 10 片）、終幕的真相、莉茲是歐里克的女兒、葛倫見過洛恩、安娜當過冒險者、商人是諾艾兒的老師。
- 文風聖經 §1 的格式規則：一句最多六十字、全形標點、對白用「」、不出現阿拉伯數字和英文、回憶裡過去的人物由旁白轉述。
- 所有機械檢查：`lineCap`（回城對話三句、相遇前後各一到四句、序章兩段各十句）、條件（`if.oath`、`full`、`notFull`、`returned`、`notReturned`）、`moodsFor`、`AVOID`、`RIN_SECRET_TERMS`、每段對話不可以提前說出的字（`story.test.ts` 的 `UNDONE`、`REVEALED`）。
- **凜在揭露之前的規則**：不叫他的名字、不說「我們」、沒有驚嘆號、不用語尾助詞；第 4 片之前不避開他的視線；序章兩段她的台詞不提鐘、結社、師父。
- 稱呼：洛恩先生（瑟蕾）、洛恩大人（千鶴）、小洛（莎菲拉）、洛恩（希爾薇）、喂，歸來者 → 洛恩（諾艾兒）、洛恩哥（波比）、老大（莉茲）、洛恩閣下 → 洛恩（絲嘉蕾）；鎮民的小兄弟、孩子、小子、拿劍的、客人／年輕人、從深處走出來的人。

## 2. 明暗分流規則（新）

### 2.1 哪些是輕的，哪些是重的

| 輕（日常，要好笑、要像人在講話） | 重（保留現在的寫法） |
|---|---|
| 城鎮台詞 `townLines`（`after` 階段尤其要輕） | 所有回憶 `mem:*` |
| 設施招呼 `greet`、`town.*.after` | `rin-reveal`、`bellkeeper-arrives` |
| 回城對話 `chat:*`（凜的第 2–4 段與洛恩的第 2–4 段除外，見下面） | 各幕節點的「發現」段落（`act2` 的石頭、`act3` 的登記簿、`act4` 的石碑） |
| 相遇 `meet.*`（被救之前可以緊張，被救之後要活起來） | 終幕 `finale`、`finaleWait` |
| `prologue-inn`、`first-return` | 鎮民交還 `town:*`（苦中帶甜，保留） |
| 流浪商人與鐘守在 `after` 階段的招呼 | 凜的 `rinLines`（第二到四幕是她的陰影，保留） |
| 提案中的閒聊（§6） | 歸鄉 `home:*`（溫暖的收尾，保留） |

**灰色地帶的處理**：
- 帶 `full`／`notFull` 兩種讀法的第 2 段回城對話（例：`chat:liz:2`、`chat:scarlet:2`）：算輕的，但可以在最後留**一句真心話**。真心話要用這個人自己的聲音說，不可以換成格言腔。
- 凜的 `chat:rin:2`–`4` 與洛恩的 `chat:hero:2`–`4` 是她的伏筆與選擇，算重的，保留。
- 幕節點的結尾如果回到旅館（例：`act2` 的喝湯段），那一小段可以輕，但這一輪不動。

### 2.2 「……」的預算

- **輕的場景：每一段最多一個「……」**（相遇的前後兩段合起來算一段）。只給真的停頓：說到一半改口、被說中、說不出口的那一下。**不可以放在句首當成開場白**。
- **城鎮台詞與招呼**：同一個設施、同一個階段的那兩三句，合起來最多一個。
- **重的場景**：不設硬上限，但一句最多一個，同一場角色台詞裡帶「……」的不超過一半。
- **替代的寫法**：
  - 用句號斷句：「沒事。不要問。」
  - 用「──」表示改口或被打斷：「看不懂──反正是好貨。」
  - 用旁白寫動作，不要讓台詞替角色嘆氣。
  - 凜原本「……再補一句」的句型，改成她自己的口癖「還有。」，平平地把話接下去（見 §3）。

### 2.3 驚嘆號

- 輕的場景每一段最多三個，只給吵的人：諾艾兒、波比、莎菲拉、莉茲、歐里克。
- 凜在選擇之前一個都不用。洛恩、希爾薇、瑟蕾、絲嘉蕾除非真的在喊，否則不用。

### 2.4 重的場景要不要小修

結論：**全部保留現在的文字**。只有兩處建議稍微修一下，等全面改寫時一起做：
1. **終幕**：22 句裡有 21 句帶「……」，夥伴交出記憶的那幾句讀起來像同一個人在講。建議只做機械性的減量：把其中大約一半的「……」換成句號或「──」，用字一律不動（例：莉茲那句「我估過了──無價」本來就很有她的味道）。
2. **相遇時凜的兩句**（`meet.selene` 的「……被圍住了，還在看月亮。」、`meet.bobby` 的「……後面。」）：相遇算輕的場景，拿掉句首的「……」，冷面的效果反而更好。

回憶裡開朗角色的「現在」反應，大多已經保有自己的口癖（莎菲拉的「喔」「囉」、波比的「喔」、莉茲的「老大」），不需要改。

## 3. 新版語氣表

每一節的格式：節奏與語域／口癖（二到四個）／日常裡哪裡好笑、哪裡可愛／怎麼逗人、怎麼被逗（配對）／稱呼／禁區。
表情一律只從規格書 §10.2 那個人自己的表情裡選。

### 洛恩（主角，`hero`）
- **節奏與語域**：句子短、問句多、聲音平。他是隊伍裡安靜的吐槽役：不會大聲吐槽，只是把事實平平地說出來，荒謬的地方就自己浮出來了。溫柔一樣是做出來的，不是說出來的。
- **口癖**：
  1. 用陳述事實來吐槽：「那是第三塊。」「剛才那個，我們是在打架。」
  2. 短問句（保留）：「想起什麼了？」「睡不著？」
  3. 主題詞「回來」（保留，留給要緊的時候用）。
  4. 被逼得沒辦法時就逃（莎菲拉要拉他跳舞），旁白寫他跑走，他自己不解釋。
- **好笑和可愛的地方**：失憶了還是很鎮定，把怪事當平常事；什麼都一學就會（過去每一輪的殘響），夥伴會覺得不公平。他會照顧人，可是不太會照顧自己（繃帶纏得亂七八糟）。
- **配對**：被波比借劍，就讓她看，然後提醒她「一下下」已經很久了；諾艾兒逞強時，他給她一個台階下（「熱身完了，就一起回去吧。」）；莉茲跟他推銷，他會付錢；凜的冷話他都接得住，但從來不追問。
- **稱呼**：所有人都叫名字。
- **改動**：文風聖經寫「絕對不會說：諷刺」，改成「**不嘲諷人**，可以有不帶刺的冷面吐槽」。英雄式的宣言、長篇大論照樣不說；主角第 9 片之前不說「我記得以前」。
- **表情**：日常多用 `normal`、`smile`，吐槽用 `normal`。`resolve`、`distant` 留給重的場景。

### 凜（`rin`）
- **節奏與語域**：全隊最短。句號多，「……」少。她的笑點都是冷面的：照字面回答問題、精準到多餘的數字、一個詞就下判決、把自己的怪習慣講得理所當然（湯一口喝完、坐在看得見門的地方）。她不是故意搞笑，是太認真了。
- **口癖**：
  1. 一個詞的判決：「不要。」「吵。」「可以。」「服。」
  2. 「還有。」──取代原本「……再補一句」的句型。她講完一件事，停一拍，再平平地接一句更直白的話（「還有。你說夢話。吵。」）。
  3. 「沒事。」用來擋問題（保留，但一段最多一次）。
  4. 揭露前叫住他時用「喂」（保留）。
- **好笑和可愛的地方**：完全不會配合別人的玩笑，但每一句都打中要害。做了好事（替他重纏繃帶），就用挑剔蓋過去。
- **配對**：
  - 莎菲拉：邀舞被拒是固定梗，而且凜拒絕的理由一次比一次精準（「跳了一拍，就會有第二拍。」）。
  - 諾艾兒：諾艾兒單方面宣布凜是勁敵，凜乾脆認輸，反而把諾艾兒氣炸（§6 閒聊二）。
  - 波比：波比想研究她的細針，她只說「不行」。
  - 希爾薇：兩個安靜的人蹲在一起看同一個方向，一句話都沒說，旁邊的人還以為她們在吵架。
  - 瑪莎：湯（保留 `act2` 的伏筆）。
- **稱呼**：揭露之前叫他「你」「喂」，不說「洛恩」、不說「我們」；`rin-reveal` 第一次叫「洛恩」；選擇之後叫「洛恩」，也會說「我們」。夥伴都叫名字。
- **禁區**：揭露之前不用語尾助詞、不用驚嘆號；第 4 片之前不避開視線；序章兩段她的台詞不提鐘、結社、師父；她的笑話**不拿自己的過去開玩笑**，也不拿「習慣」來解釋她的反射動作。
- **選擇之後**：可以用「呢」，笑話變得比較暖（`rinOath` 的「我現在會眨眼了。……看你的時候，也是。」就是這個方向）。
- **表情**：揭露之前日常用 `guarded`、`normal`；不設門檻的場景（相遇、`chat:safira:2`、閒聊）一律用 `normal` 或 `serious`，因為它們可能在她選擇之後才播。

### 瑟蕾（`selene`）
- **節奏與語域**：說話慢，句尾用「呢」「吧」，像在念星象。她的笑點是天然呆加上距離感：什麼小事都用月相來「預報」，說完又怕預言成真，趕快收回。
- **口癖**：
  1. 月相比喻（保留）：「今晚是下弦呢。」
  2. 「也許」（保留）。
  3. 把責任推給月亮：「是月亮說的，不是我說的呢。」
  4. 講完又收回：「剛才那句，請當作沒聽見吧。」
- **好笑和可愛的地方**：明明可以「預言」晚餐吃什麼，就是不肯說。在洞窟裡看不到月亮就會迷路，所以老是抬頭看天花板。
- **配對**：諾艾兒逼她預言（「本小姐明天會不會更強？」「也許呢。」諾艾兒抓狂）；莉茲想讓她猜寶箱（「月亮不管寶箱的事呢。」）；和千鶴一起慢慢喝茶，安靜到莎菲拉坐不住。
- **稱呼**：洛恩先生，用「您」；集滿之後叫洛恩，用「你」（保留）。夥伴叫名字。
- **禁區**：不斷言未來（「一定」「注定」）；「我想看見」留給她第 5 片。
- **表情**：預報用 `foresee`，收回用 `wistful`，被逗笑用 `smile`。

### 千鶴（`chizuru`）
- **節奏與語域**：端正、句子完整、偏文言，遇到新東西會停一拍。她的笑點是時代錯位：用舊的說法講新東西，為了小事行大禮，把別人的玩笑當真。
- **口癖**：
  1. 「失禮了。」（保留）
  2. 「甚好。」（保留）
  3. 「此處」「此物」「莫非」。
  4. 看到新東西會問：「此為何物？」（`bewildered`）
- **好笑和可愛的地方**：認真到可愛。對波比的機關合掌行禮（「莫非有靈附身？」），聽不懂莉茲的俚語（「『搞定』……是何種兵法？」）。
- **配對**：波比（機關嚇到她）；莉茲（俚語翻譯不過來）；絲嘉蕾（兩個人互相回禮，誰都停不下來）；被莎菲拉拉去跳舞，結果跳成了祭典的神樂。
- **稱呼**：洛恩大人（不改）。夥伴叫「〇〇姑娘」（新發明，見 §7）。
- **禁區**：流行語、粗話；第 4 片之前不說神社不在了；回城對話不說「回神社」（`UNDONE`）。

### 莎菲拉（`safira`）
- **節奏與語域**：快、跳，句子有節拍（短、短、長），句尾用「啦」「囉」。她的笑點是什麼都能變成舞：幫人取綽號、講話很戲劇化、被拒絕了也很開心。
- **口癖**：
  1. 「跟上拍子囉。」（保留）
  2. 「這一步踩空啦。」（失敗的時候）
  3. 數拍子：「一、二──」
  4. 幫人取綽號：小洛（保留）、小希（希爾薇，新發明）。
- **好笑和可愛的地方**：拉人跳舞是她的固定梗。她會用評舞的方式評戰鬥（「剛剛那一刀，踩在拍子上，漂亮！」）。
- **配對**：凜（邀舞被拒）；希爾薇（硬把她拖下場）；絲嘉蕾（把舞步當成操練，結果跳得最整齊）；洛恩（他每次都逃）。
- **稱呼**：小洛；開玩笑時叫「歸來者大人」（保留）。她從來不說「洛恩」（測試會檢查）。
- **禁區**：不說「累」；第 4 片之前不提團長、不提「做決定的」；不提團員的名字；她的玩笑不碰舞團。
- **表情**：逗人用 `wink`，大笑用 `laugh`。笑聲底下的罪惡感用 `sad`，只放在回憶和真心話裡。

### 希爾薇（`sylvie`）
- **節奏與語域**：句子極短，不用語尾助詞。她和凜的差別：凜是冷的、精準的；希爾薇是土的、具體的，用看動物和天氣的方式看人。她的笑點是太直白、太實際，被稱讚的時候完全不知道怎麼反應。
- **口癖**：
  1. 「風向變了。」（保留）
  2. 拿動物比人：「吵。像雨季的青蛙。」
  3. 「這個能吃。」「那個不能。」
  4. 「不用。」
- **好笑和可愛的地方**：全隊最實用的人。被拉去跳舞時，眼睛只在找退路；削箭的時候不准波比靠近，因為機關的聲音會把獵物嚇跑。
- **配對**：莎菲拉（被拖下場，§6 閒聊一）；波比（她叫波比「松鼠」）；凜（安靜的同類）；莉茲（莉茲想把她採的藥草拿去賣）。
- **稱呼**：洛恩（不改）。夥伴叫名字。
- **禁區**：不誇自己、不說累；第 5 片之前不說「我把人帶出去了」。**回城對話裡不可以出現「林子」「守林」「種子」「發芽」**（`REVEALED` 第 1 片），所以日常的比喻只能用樹、風、葉子、動物。
- **表情**：`alert` 留給她真的在聽動靜的時候；被稱讚時用 `blush`；`unguarded` 照規格書留給心契與後日談。

### 諾艾兒（`noel`）
- **節奏與語域**：吵、快，全隊驚嘆號最多的人，常用「哼」開頭。被說中就結巴，自稱掉回「我」。她的笑點是誇大其詞、自己封自己稱號、單方面宣戰，然後嘴硬到打臉自己。
- **口癖**：
  1. 「哼。」（保留）
  2. 「本小姐的雷可是很貴的。」（保留）
  3. 被說中的時候：「那、那是……！」
  4. 「不准笑。」「不准看。」
- **好笑和可愛的地方**：小東西也要取個大名字（筆記本上畫的「雷獸」，看起來像貓）。幫了忙要說成施捨，想道謝又說不出口，只好繞一大圈。
- **配對**：凜（勁敵宣言，凜乾脆認輸）；瑟蕾（逼她預言）；莉茲（莉茲幫她的雷估價：「這發雷，市價兩枚銅板。」「才兩枚？！」）；流浪商人恢復之後，她在他面前不用「本小姐」（保留）。

## 6. 提案：城鎮閒聊（`banter`，需要引擎支援）

**這是新的功能，要先經過使用者核准，再交給寫程式的 agent。** 現在的引擎沒有這種場景。

- **是什麼**：回城的時候，兩個夥伴自己聊起來，洛恩在旁邊聽（他最多說一句，或者完全不說話，由旁白寫他的反應）。目的是補上「夥伴之間幾乎不說話」這個缺口。
- **需要的引擎支援（草案）**：
  - 新的場景種類 `banter:<甲>-<乙>:<n>`，`lineCap` 是四。
  - 觸發條件：兩個人都已經遇見（`BANTER_GATE`，用法和 `CHAT_GATE` 一樣，可以再加 `stage` 或 `oath`）。
  - 一次回城最多播一段，排在回城對話後面。
  - 手冊可以重看。
  - 測試的豁免：這種場景沒有「主人」，所以兩個說話的人都要帶 `if.met`，或者由閘門保證她們已經遇見。
  - 凜在閒聊裡的規則和在回城對話裡一樣：不設門檻的話，不用 `guarded`／`averted`，也不叫名字、不說「我們」。
- **語氣**：屬於輕的場景，「……」最多一個。

### 閒聊一：莎菲拉 × 希爾薇（`banter:safira-sylvie:1`）

```ts
{ who: 'safira', mood: 'laugh', text: '「跳舞不用退路啦！……欸，小洛，她真的從第三條跑了。」' },
```
