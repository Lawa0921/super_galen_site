## (1) 第一次聽出碎片是誰的（`town:marta` 的發現版）

時機：第二幕以後，撿到瑪莎碎片之後的第一次回城（v6 spec §9.1）。在那之前撿到的其他鎮民碎片都是「認不出的聲音」。
地點：旅館廚房，不是公會櫃台。

### 原稿（現行 `town:marta`，`story.zh-TW.ts:1463-1474`，在公會交還）

- 旁白：月影旅館的廚房。瑪莎把碎片貼在胸口，爐上的湯咕嘟咕嘟地響。
- **瑪莎**：「想起來了。他走的那天早上，我也在煮這鍋湯。」
- **瑪莎**：「他是冒險者。出門前說：『回來的時候，把今天的事說給我聽。』」
- **瑪莎**：「我一直怕，那天沒跟他說路上小心。……原來說了。追到門口，說了兩次。」
- **瑪莎**：「那本日記，原來是寫給他的。他回來的時候，我要說得出每一天。」
- **洛恩**：「那以後就不用寫了？」
- **瑪莎**：「還是會寫。現在想記住的事變多了。你們的事，一件也不想漏。」
- **瑪莎**：「這兩根復活羽毛，是他留在家裡的，你們帶著。往後的飯菜，我多添一道。」

### 改寫

- 旁白：月影旅館的廚房，深夜。洛恩把今天撿到的一塊碎片放在桌上。它發著淡淡的光，交易所說值兩枚銀幣。
- **洛恩（心聲）**：（又來了。一拿起來，就有人在說話。）
- **凜**：「你又拿著那塊發呆。」
- **洛恩**：「它在講話。」
- **凜**：「石頭不會講話。」
- **洛恩**：「這塊會。一個女人，一直說『路上小心』。說兩次。」
- **凜**：「你昨天說那塊在哭。前天那塊在數羊。另外，我一次也沒聽見。」
- **洛恩（心聲）**：（只有我聽得見。醒來才一個月，我還不確定這是本事，還是病。）
- 旁白：瑪莎提著燈走進廚房，看見桌上的光。
- **瑪莎**：「又撿這些亮晶晶的回來？交易所收的，拿去換錢，明天的肉錢就有了。」
- **洛恩**：「瑪莎，這個聲音，我聽過。」
- **瑪莎**：「石頭的聲音？孩子，你累壞了。」
- **洛恩**：「『路上小心』。妳每次在門口送我們，都說兩次。」
- 旁白：瑪莎手裡的燈晃了一下。
- **瑪莎**：「誰都會說兩次。吃了沒？湯還溫著──」
- **洛恩**：「妳每次被問到那一天，就去端湯。」
- **瑪莎**：「……哪一天？」
- **洛恩**：「妳家那口子出門的那一天。」
- **瑪莎**：「那天……我想不起來。我只記得我一直怕，那天沒跟他說路上小心。」
- **洛恩**：「拿著。」
- 旁白：瑪莎接過碎片。光在她掌心化開，她站了很久，爐上的湯咕嘟咕嘟地響。
- **瑪莎**：「說了。我追到門口，說了兩次。他笑我，說一次就聽見了。」
- **瑪莎**：「他出門前說，回來的時候，要我把每天的事說給他聽。那本日記，原來是寫給他的。」
- **瑪莎**：「洛恩，這不是什麼亮晶晶的石頭。這是我的那一天。」
- **洛恩（心聲）**：（交易所收它兩枚銀幣。）
- **凜**：「那剩下那幾塊，也是誰的哪一天。」
- **洛恩**：「明天全部拿去給安娜。一塊一塊找主人。」
- **瑪莎**：「這兩根復活羽毛，是他留在家裡的，你們帶著。往後的飯菜，我多添一道。」

**改了什麼、為什麼**
- **這是洛恩第一次認出碎片的主人**，由他的本事帶出來，不是由誰來解說：
  - 碎片不是結晶，是某個人的一天；
  - 鎮上的人丟掉的東西，就在下面。
- **洛恩主動追問**：他兩次戳破瑪莎繞開那個洞的方式（說兩次、去端湯）。真相是他問出來的，不是瑪莎自己回憶的獨白。
- **失憶只在洛恩和凜身上**：「醒來才一個月」「我一次也沒聽見」。
- **瑪莎守住鎮民的規則**：她一開始只當碎片是結晶，被碰到那個洞時晃了一下，然後轉話題。
- **原稿的資訊全部保留**：說了兩次、日記是寫給他的、復活羽毛、多添一道菜。原稿「還是會寫」那一段可以留在之後的招呼裡。

**新發明（已登記在帳本 I-229 起）**
- 只有洛恩聽得見碎片。
- 前幾天他聽過「在哭」「在數羊」的碎片。
- 交還的地點改在旅館廚房。
- 瑪莎是第一個被認出的主人；在她之前的鎮民碎片認不出、不能交還（v6 spec R21、R23）。

**超出現行測試**
- `town:*` 上限八句，改寫 28 句。
- 心聲是新的台詞類型。
- 凜選擇前的規則都守住：無名字、無我們、無助詞、無「！」，補句用「另外，」。

## (2) 為了淘金加入：莎菲拉（`join:safira`，取代 `meet.safira`）

時機：熾焰之地的門第一次擲出之後的第一次回城（v6 spec R29）。地點：黃昏的傳送門廣場。

### 原稿（現行 `meet.safira`，`story.zh-TW.ts:2116-2129`，迷宮裡被救）

**被救之前**
- 旁白：有人被怪物圍住了！
- 旁白：熾焰之地的火海裡，一個少女握著彎刀，一個人跳著劍舞。每一步，都像在等誰接上她的拍子。
- **莎菲拉**：「哎呀，有觀眾！來得剛好，這首一個人跳太寂寞了呀。舞伴又一個比一個醜。」
- 旁白：凜的腳尖跟著那拍子點了一下，又立刻停住。

**被救之後**
- **莎菲拉**：「哈哈，好久沒人陪我跳完一整首了！你們踩拍子的腳，還不錯唷。」
- **洛恩**：「我是洛恩。剛才那個，我們是在打架。」
- 旁白：她轉過身，朝空蕩蕩的火海喊：「鼓手大叔，下一首快一點！」火海裡，什麼也沒有回答。
- **莎菲拉**：「啊，喊錯人了。那就你們吧，一、二──我是莎菲拉。你的名字太硬，叫小洛好了。跟上拍子囉！」

### 改寫

- 旁白：黃昏的傳送門廣場。一個赤腳的少女在石板中央跳劍舞，腳踝的銅環一響一響。打賞的碗裡，三枚銅板。
- **莎菲拉**：「最後一圈──謝謝各位！不給錢的，也請給掌聲唷！」
- **洛恩（心聲）**：（我拍手了。錢在凜那裡。）
- 旁白：凜的腳尖跟著那拍子點了一下，又立刻停住。
- **莎菲拉**：「欸，你！你就是那個歸來者？從最下面走上來的那個？」
- **洛恩**：「是我。我是洛恩。」
- **莎菲拉**：「那你一定知道寶藏在哪！帶我去熾焰之地。聽說那裡的火裡埋著古代的金飾，一件就能換一面好鼓。」
- **洛恩**：「我不知道寶藏在哪。下面的事，我一件都不記得。」
- **莎菲拉**：「一件都不記得？那你怎麼當上傳說的呀？」
- **洛恩**：「別人替我當的。我只是走上來。」
- **凜**：「他連自己幾歲都不知道。我也不知道。」
- **莎菲拉**：「哈哈，你們兩個好慘！算了，不記得也沒關係。你們回得來，這就夠了。」
- **洛恩**：「妳要鼓做什麼？」
- **莎菲拉**：「重組一個舞團呀。要鼓手、要吹笛的、要縫衣服的，全部要錢。在那之前，我先一個人跳。」
- **洛恩**：「原本的舞團呢？」
- **莎菲拉**：「沙漠起霧的那一晚，散了。我被沙暴推了出來，其他人……被霧帶去哪裡，誰也不知道。」
- **洛恩（心聲）**：（說「散了」時，她的腳停了半拍。剛才整支舞一拍都沒停。）
- **莎菲拉**：「好啦，不說這個。我是莎菲拉。你的名字太硬，叫小洛好了。」
- **洛恩**：「熾焰之地的門今天開了。明天一早，在這裡。」
- **莎菲拉**：「成交唷！分成怎麼算？」
- **凜**：「金飾歸妳。碎片歸他。另外，碗裡那三枚收好，也是錢。」
- **莎菲拉**：「凜凜好精。一、二──跟上拍子囉！」

**改了什麼、為什麼**
- **加入的理由是淘金，不是被救**：她要金飾、換鼓、重組舞團。她主動找上洛恩，是因為「歸來者」的傳說；而洛恩直接戳破傳說：「我一件都不記得」。
- **家鄉在下面，現在誰都不知道**：
  - 她只知道沙漠起了霧、舞團散了、人不知道去哪了；
  - 熾焰之地就是那片沙漠，要等她的第五段才發現；
  - 原稿的「鼓手大叔」在火海裡喊錯人，改成「腳停了半拍」，由洛恩的心聲看見。
- **她的秘密只露出一角**：「散了」時停了半拍。她跑在最前面這件事，一個字都沒說。
- **失憶只在洛恩和凜身上**：「一件都不記得」「連自己幾歲都不知道」。
- **保留原稿的四個梗**：凜的腳尖跟拍子、小洛、「跟上拍子囉」、凜凜。

**守住的門檻**
- 莎菲拉不說團長、團員的名字，也不說她跑在前面。
- 她從不說「洛恩」，只叫「小洛」。
- 凜的規則全部照舊。

**新發明（已登記在帳本 I-229 起）**
- 廣場賣藝、古代金飾的傳聞、重組舞團。
- 「被沙暴推出來」（v5）。
- 鎮上加入的觸發條件：門第一次出現。

**超出現行測試**
- 新的場景種類 `join:*`，共 22 句。
- 莎菲拉的「！」四個，超過輕場景每段三個的上限。

## (3) 城鎮群戲：碎片的價錢，以及錯的霧理論（`group:act2`，`story.zh-TW.ts:453-470`）

時機：第二幕節點那一晚。洛恩在第一幕就聽得見碎片在說話，但通常還沒認出瑪莎（她的碎片第五層起才掉）。

拉扯的四方：
- **凜**：賣掉，還人情，早點還完早點走。
- **諾艾兒**：吸收變強，還搬出「霧是魔力廢氣」的理論。
- **瑟蕾**：看見了，不能說。
- **洛恩**：每一片都是某個人的一天。

### 原稿

- 旁白：月影旅館的晚飯。碗收走以後，桌上攤開一塊布，布上是找不到主人的碎片。瑟蕾拿起一片，對著燈看了很久。
- **凜**：「一共十一片。明天全部拿去交易所換錢，照人頭分，誰也不欠誰。」
- **諾艾兒**：「換錢？裡面是光耶！吸進去，本小姐的雷能再亮一倍。」
- **凜**：「吸進去，別人的東西就長在妳身上。」
- **諾艾兒**：「說得好像妳很懂。」
- **凜**：「不懂。所以明天賣。」
- **諾艾兒**：「瑟蕾，妳盯著那片看了那麼久，一定看到了什麼吧？看到又不講，很賊耶。」
- 旁白：瑟蕾摸出一枚銅板。
- **瑟蕾**：「那就……問問月亮吧。」
- 旁白：她把它往上一彈。洛恩伸手接住，放回她的手心。
- **洛恩**：「妳自己說。」
- **瑟蕾**：「不賣也不吸。我那一份，請瑪莎收進廚房的抽屜，等它的主人。」
- 旁白：凜把自己那份包好，擱在腳邊。大家看著瑟蕾的時候，諾艾兒把一片滑進了袖子；洛恩看見了，什麼也沒說。

### 改寫

- 旁白：月影旅館，晚飯後。桌上攤著一塊布，布上攤著十一片碎片。瑟蕾拿起一片，對著燈看了很久。
- **凜**：「十一片。明天拿去交易所，換的錢照人頭分，誰也不欠誰。」
- **洛恩**：「不賣。我都聽過了，每一片裡都有人在說話。」
- **諾艾兒**：「又來了，『我聽見了』。整條街只有你聽得見，誰知道是不是你睡迷糊了？」
- **洛恩**：「昨天那一片在數羊，數到四十七少一隻。我沒睡迷糊。」
- **諾艾兒**：「那、那是剛好！反正給本小姐吸。雷亮一倍，最底下那隻頭目就打得到！」
- **洛恩**：「吸了，那個人的一天就沒了。」
- **諾艾兒**：「才不會！霧就是魔力的廢氣，碎片是廢氣結成的渣。本小姐吸一片，霧就少一點，這叫打掃！」
- **凜**：「吸進去，別人的東西就長在妳身上。」
- **諾艾兒**：「說得好像妳很懂。」
- **凜**：「不懂。另外，霧濃，是有東西快結束了。」
- **洛恩**：「什麼東西？」
- **凜**：「不知道。嘴巴自己說的。」
- **洛恩（心聲）**：（她偶爾會說出自己也不懂的話。我也會。兩本撕掉前半的書。）
- **凜**：「總之賣。另外，我那一份給你，算還人情。錢算半次，還差一次半。」
- **諾艾兒**：「瑟蕾！妳盯著那片看了那麼久，一定看到了什麼吧？看到又不講，很賊耶。」
- **瑟蕾**：「看到了。不能說。說了，就會變成真的。」
- **諾艾兒**：「那至少說，霧到底是什麼？」
- **瑟蕾**：「月亮說，是有人哭不完的眼淚。……不，這句不算。」
- 旁白：她摸出一枚銅板，往上一彈。洛恩伸手接住，放回她手心。
- **洛恩**：「月亮不在桌上。妳自己說。」
- **瑟蕾**：「不賣，也不吸。我那一份，請瑪莎收進廚房的抽屜，先放著。」
- **洛恩**：「我那份也先放著。在我聽懂它們在說什麼之前，誰都別賣。」
- 旁白：凜把自己那份包好，擱在腳邊。大家看著瑟蕾的時候，諾艾兒把一片滑進了袖子；洛恩看見了，什麼也沒說。
- **洛恩（心聲）**：（袖子裡那一片，在小聲數羊。明天再說。）

**改了什麼、為什麼**
- **三種霧理論，都只對了一點**：
  - 諾艾兒的「魔力廢氣」是自私的錯理論，用來合理化吸收。
  - 凜的「有東西快結束了」是她被養大時聽的教義，說的是燈快死了。她自己不懂，玩家到第四幕才懂。
  - 瑟蕾的「哭不完的眼淚」最接近真相（艾斯特拉倒進燈裡的悲傷），她說完立刻收回。
- **洛恩的聽力讓他站得住立場**：「我都聽過了」「昨天那一片在數羊」。諾艾兒懷疑他「睡迷糊了」，這是 v6 的新拉扯。結尾他連袖子裡那一片在說什麼都聽得見。
- **失憶只在洛恩和凜身上**：「嘴巴自己說的」「兩本撕掉前半的書」。
- 原稿的十一片、交易所、照人頭分、「別人的東西長在妳身上」、「說得好像妳很懂」、銅板、「妳自己說」、瑪莎的抽屜、袖子那一片，都還在。

**守住的門檻**
- 凜在第二幕、選擇之前：不提鐘、結社、師父；教義只露出一句她不懂的話。
- 諾艾兒不說老師、偷書。
